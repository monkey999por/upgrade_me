# 12月以降検討

8週間（〜11/22）ではやらず、判定のあとに検討するもの。

## 肌：有効成分を足す（洗顔と保湿が習慣になってから）
### まず毛穴のタイプを見る
| タイプ | 見た目 | 主な原因 | 合う成分 |
|---|---|---|---|
| 詰まり・黒ずみ | 小鼻・Tゾーンのぽつぽつ。黒いのは詰まった皮脂の酸化 | 皮脂＋古い角質 | レチノール、ナイアシンアミド、サリチル酸 |
| 開き | 頬などで丸く開いて見える | 皮脂が多い（男性ホルモン・遺伝） | ナイアシンアミド、レチノール |
| たるみ | 頬で縦長・しずく形 | 年齢・乾燥・紫外線 | レチノール、日焼け止め |

- 毛穴を押し出す・パックで引き抜くのはしない（広がる・炎症の原因）

### 成分
| 成分 | 何に効く | 注意 |
|---|---|---|
| **ナイアシンアミド** | 皮脂を減らす（日本人で2%・4週間）、毛穴の目立ち、肌荒れ防止 | 刺激が少ない。**最初の1つに向く** |
| **レチノール** | 毛穴・ハリ・小じわ。効果が出るまで12週間 | 刺激が出やすい（下の使い方） |
| ビタミンC | シミ・くすみ・紫外線による老化 | 純粋なビタミンCは不安定。誘導体は穏やかだが研究は少ない |
| サリチル酸 | 詰まり | 化粧品は0.2%までで、ピーリング効果はあまり期待できない |

### レチノールの種類
| 種類 | 表示名 | 強さ |
|---|---|---|
| レチノール誘導体 | パルミチン酸レチノール・酢酸レチノールなど | 穏やか。初めてならここから（例：無印良品の0.1%美容液） |
| 純粋レチノール | レチノール | 誘導体より強い。2017年に資生堂の純粋レチノールが医薬部外品の「シワ改善」成分として認められた |
| 処方薬（アダパレン） | ディフェリンゲル | ニキビ・詰まり（面皰）に保険で出る。皮膚科で相談 |

### レチノールの使い方
1. 夜だけ、洗顔 → 保湿の間（または保湿のあと）に薄く
2. 週2–3回から始めて、2週間おきに回数を増やす。慣れたら毎晩
3. 始めて2–4週間は赤み・皮むけ・ヒリヒリが出やすい。強ければ回数を減らす。写真の前夜は使わない
4. 使っている間は日焼け止めを毎日
5. サリチル酸・ピーリングと同じ日に重ねない。ダーマペンをやるなら施術の1週間前から止める

### スキンケアの順番（全部使う場合）
洗顔 → 化粧水 → 美容液（有効成分） → 乳液・クリーム → 日焼け止め（朝だけ）

## 肌：ダーマペン
洗顔とレチノールで足りないと感じたら。契約は[04の契約ルール](04_skin-teeth.md)どおり。

### 皮膚科の選び方
**条件**：①皮膚科専門医が在籍（[皮膚科専門医MAP](https://www.dermatol.or.jp/spmap/)）、②毛穴・ニキビ跡の施術メニューがある、③料金表を公開している

| 院 | 場所 | 毛穴向けの施術 |
|---|---|---|
| はなふさ皮膚科 大宮院 | 大宮駅西口 徒歩2分 | ダーマペン、フラクショナルレーザー、ポテンツァ、炭酸ガスレーザー、ケミカルピーリング |
| 肌クリニック大宮 | 大宮駅西口（アクロスキューブ大宮5F） | 毛穴黒ずみダーマペン、ニードルRF、ピコフラクショナル、炭酸ガスフラクショナル |
| 大宮西口皮フ科形成外科 | 大宮駅西口 | 要確認 |
| 桜木皮膚科 / あづま皮膚科 / ひかりクリニック | 大宮区内 | 要確認（保険診療が中心の可能性） |

→ 上の2院でカウンセリング

### 2院のダーマペンの比較
| | はなふさ皮膚科 大宮院 | 肌クリニック大宮（毛穴黒ずみダーマペン） |
|---|---|---|
| 料金（税込） | 両頬 トライアル13,200円／両頬＋こめかみ＋鼻 トライアル16,500円／全顔 トライアル22,000円（5回コースもあり）。看護師が施術 | 両頬＋鼻 27,000円／鼻 18,800円／顔全体 28,600円（別に診察料1,500円） |
| 間隔・回数 | 3–8週間おき | 2週間〜1ヶ月おき、1–3回 |
| ダウンタイム | 赤みは数時間〜数日。まれに内出血が出ると消えるまで1–2週間 | 腫れ・赤みは1–3日。内出血が出ると1–2週間 |
| 向いている毛穴 | **開き**・ニキビ跡 | **黒ずみ・詰まり**（薬剤を塗って行う） |

→ カウンセリングで診断される毛穴のタイプで選ぶ

### ダーマペンの間隔と回数
- 開き型：4週間おき。黒ずみ・詰まり型：2週間おき
- 施術は筋トレのない日の前日に入れる（例：水曜に施術 → 木曜が休養）
- 大事な写真・予定の2週間前までに終える
- 回数券は1回目の結果を見てから

### 施術の前後に守ること
| 時期 | やること |
|---|---|
| 施術の1週間前〜 | レチノール・ピーリング系を使わない |
| 施術当日 | 院の指示どおり（洗顔・メイクの制限。例：4時間は洗顔しない、24時間はメイクしない、ワセリンで保湿） |
| 当日〜翌日（48時間） | **筋トレ・HIITは休み**。歩くのも汗をかかない程度に。サウナ・長風呂・お酒も控える（体温が上がりやすいので48時間とる） |
| 3日目〜 | 普段どおり。汗は清潔なタオルで押さえて拭く（こすらない） |
| 3日間 | プール・サウナに入らない |
| ずっと | **日焼け止めを毎日** |

### カウンセリングで聞くこと
- 自分の毛穴のタイプ（黒ずみ・詰まり／開き／たるみ／ニキビ跡の凹み）はどれか
- 勧める施術と、その理由（ダーマペン・ピコフラクショナル・ニードルRFの違い）
- 1回あたりの料金、推奨回数と間隔、総額
- ダウンタイム（赤み・かさぶたの期間）
- **施術する医師の資格**（皮膚科専門医が施術するのか、看護師か）
- 施術前後に気をつけること（レチノール・日焼け・運動・プール）
- 毛穴のタイプに合わせた間隔（2週間おき or 4週間おき）と回数
- （ついでに）あご下の脂肪・たるみに医療でできることと費用
