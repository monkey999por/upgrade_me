# 12月以降検討

8週間（〜11/22）ではやらず、判定のあとに検討するもの。

## 肌：レチノール
- 夜の洗顔が習慣になってから始める
- 濃度の低いもの（0.1%前後）を週2–3回の夜から。慣れたら毎晩
- 始めて2–4週間は赤み・皮むけが出やすい。写真の前夜は使わない
- 使っている間は日焼け止めを毎日。ダーマペンをやるなら施術の1週間前から止める
- サリチル酸などのピーリング系と同じ日に重ねない

## 肌：ダーマペン
洗顔とレチノールで足りないと感じたら。契約は[04の契約ルール](04_skin-teeth.md)どおり。

### 皮膚科の選び方
**条件**：①皮膚科専門医が在籍（[皮膚科専門医MAP](https://www.dermatol.or.jp/spmap/)）、②毛穴・ニキビ跡の施術メニューがある、③料金表を公開している

| 肌クリニック大宮 | 大宮駅西口（アクロスキューブ大宮5F） | 毛穴黒ずみダーマペン、ニードルRF、ピコフラクショナル、炭酸ガスフラクショナル |

### ダーマペンの間隔と回数
- 開き型：4週間おき。黒ずみ・詰まり型：2週間おき
- 施術は筋トレのない日の前日に入れる（例：水曜に施術 → 木曜が休養）
- 大事な写真・予定の2週間前までに終える
- 回数券は1回目の結果を見てから

### 施術の前後に守ること
| 時期 | やること |
|---|---|
| 施術の1週間前〜 | レチノール・ピーリング系を使わない |
| 施術当日 | 院の指示どおり（洗顔・メイクの制限。例：4時間は洗顔しない、24時間はメイクしない、ワセリンで保湿） |
| 当日〜翌日（48時間） | **筋トレ・HIITは休み**。歩くのも汗をかかない程度に。サウナ・長風呂・お酒も控える（体温が上がりやすいので48時間とる） |
| 3日目〜 | 普段どおり。汗は清潔なタオルで押さえて拭く（こすらない） |
| 3日間 | プール・サウナに入らない |
| ずっと | **日焼け止めを毎日** |

### カウンセリングで聞くこと
- 自分の毛穴のタイプ（黒ずみ・詰まり／開き／たるみ／ニキビ跡の凹み）はどれか
- 勧める施術と、その理由（ダーマペン・ピコフラクショナル・ニードルRFの違い）
- 1回あたりの料金、推奨回数と間隔、総額
- ダウンタイム（赤み・かさぶたの期間）
- **施術する医師の資格**（皮膚科専門医が施術するのか、看護師か）
- 施術前後に気をつけること（レチノール・日焼け・運動・プール）
- 毛穴のタイプに合わせた間隔（2週間おき or 4週間おき）と回数
- （ついでに）あご下の脂肪・たるみに医療でできることと費用
