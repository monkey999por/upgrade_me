# 02 食事

**アプリには記録しない。** このページの表から食材を選び、キッチンスケールで量って食べる。うまくいっているかは、毎朝の体重・体脂肪（とウエスト）だけで見る。

## 1日の目標
| 項目 | 目標 |
|---|---|
| カロリー | **1,900 kcal** |
| タンパク質 | **165–175 g**（1食30g以上 × 4回） |
| 脂質 | 45–60 g |
| 糖質 | 190–200 g（筋トレ前の昼に多め、夜に少なめ） |
| 食物繊維 | 20 g以上 |
| 食塩 | 7.5 g未満（調味料は6gまで） |
| 水 | 1日2L前後 |
| お酒 | 週1回・2杯まで |

---

## 1日の組み立て方
1食ごとに **枠を1つずつ選んで量る**。これを守れば、どの組み合わせでも1日 約1,850–1,950kcal・P160–175g になる。
| 食事 | 選ぶもの | 目安 |
|---|---|---|
| **朝** | [朝の型](#朝の型4種類どれも約530580kcalp3238g) A–D から1つ | 約550kcal・P32–38g |
| **昼** | ①メイン **1食分** ＋ ②主食 **ご飯150g相当** ＋ ④野菜 150g以上 | 約450–550kcal・P40g |
| **間食** | [間食の型](#間食の型約260300kcalp2535g) から1つ（15:30 or 筋トレ後） | 約300kcal・P30g |
| **夜** | ①メイン **1.2倍** ＋ ②主食 **ご飯100g相当** ＋ ③豆腐150g ＋ ④野菜 100g以上 ＋ 油7g | 約550kcal・P55g |

- **PFCのコツ**：迷ったら「メインは脂の少ないもの（F10g以下）」「主食は量を守る」「油は1日7gまで」。この3つでほぼ目標に入る
- 脂の多いメイン（さば・ぶり・サーモン）の日は、**アーモンドとオリーブ油をなし**にする
- 料理の調味料はカロリーに入れて考える（下の⑥調味料）。照り焼き・生姜焼きのように甘い味付けは +50kcal ほど

### 量り方
- キッチンスケールに器をのせて **0g に戻してから** 量る
- 肉・魚は **調理前の生の重さ**、ご飯は **炊いた後の重さ**、麺は表に書いた状態（ゆで or 乾麺）
- 油は **小さじで量る**（小さじ1＝4g、目分量で回しかけない）
- 慣れるまでの2週間は毎回量る。その後も **ご飯・肉・油** は量り続ける（ずれやすい3つ）

## 1週間の献立例
量は [料理の例](#料理の例1食分量つき) と [1日の組み立て方](#1日の組み立て方) のとおり。火・木の昼はコンビニの例（自炊でもよい）。
| 曜日 | 朝 | 昼 | 夜 |
|---|---|---|---|
| 日 | A 和の定番 | 鶏むねの塩麹焼き・ご飯・ブロッコリー・トマト | **牛もも赤身**ステーキ・玄米ご飯・ほうれん草のおひたし・豆腐としめじ |
| 月 | B オートミール | 鶏ももの照り焼き・ご飯・キャベツとにんじんの蒸し野菜 | **生鮭**のホイル焼き・ご飯・小松菜・冷奴 |

| 水 | C パン | ささみの梅しそ焼き・ざるそば・オクラと納豆 | **さば**の塩焼き100g・ご飯・大根おろし・豆腐とまいたけ（油・アーモンドなし） |

### 筋トレの日の食べ方
- ご飯は **筋トレ前の昼に150g、後の夜に100g**
- 筋トレ前に空腹なら、間食の一部（バナナ・おにぎり）を先に。プロテインは筋トレ直後でもよい
- 休養日も食べる量は同じ

## お腹が空きやすいとき（腹持ちのいい選び方）
同じ枠の中で入れ替えるだけ。カロリーは変わらない。
| 枠 | 腹持ちがいい | 空きやすい |
|---|---|---|
| ① メイン | 鶏むね・ささみ・たら・えび・いか・まぐろ（低脂質で量が多い）・卵 | 脂の多い肉・魚（量が少ない） |
| ② 主食 | じゃがいも・さつまいも（蒸し）・オートミール・玄米・そば | 白いパン・うどん |
| 間食 | [間食の型](#間食の型約260300kcalp2535g)の「コンビニ」「豆と乳製品」（噛むもの） | プロテインを飲むだけ |
| ④ 野菜など | きのこ・海藻・葉野菜を多めに。みそ汁・スープ（具を多く） | — |
| ⑤ 果物 | りんご・みかん・キウイ（丸ごと） | ジュース・スムージー |

- **汁物と野菜から先に** 食べる。**よく噛んで15–20分かける**
- カロリーは **飲まない**（甘いコーヒー・ジュース）

## コンビニの日（外出の日の昼など）
**目安：450–550kcal・タンパク質40g前後**。商品の表示を見て選ぶ。

| セット | 中身 | 目安 |
|---|---|---|
| ① 定番 | サラダチキン1個＋鮭おにぎり1個＋ゆで卵1個＋カップのサラダ（ノンオイルドレッシング） | 約410–500kcal / P40g |
| ② 麺の気分 | ざる蕎麦＋サラダチキン＋ゆで卵 | 約550kcal / P40g |
| ③ 時間がない | 高たんぱくヨーグルト＋プロテインドリンク＋おにぎり1個 | 約450kcal / P40g |

- 選び方：**P20g以上の商品1つ**＋主食1つ＋野菜1つ
- 避けるもの：菓子パン、揚げ物、カップ麺、甘い飲み物、マヨネーズ系のサラダ
- 夜にブロッコリー100gを追加する

## 寿司の日（週1回、夜）
- **8–10貫**：サーモン・ぶり・さば・いわし・赤身を中心に。1貫はおよそ50–70kcal
- 巻物・揚げ物・マヨネーズ系の軍艦は選ばない。味噌汁はOK（塩分は多め）
- その日はアーモンドとオリーブ油をなしにする

## 外食の日（週1回まで）
- 定食屋：焼き魚定食・生姜焼き（ご飯少なめ）。揚げ物は選ばない
- 焼肉：赤身・ハラミ・タン中心、ご飯小
- 次の日は基準に戻すだけ（食事を抜かない）

| サプリ | 量 | いつ飲むか |
|---|---|---|
| プロテイン | 1日1杯（30g） | 間食 or 筋トレ直後 |
| ビタミンD | 25μg（1,000IU） | **夜が肉の日だけ**、朝食と一緒に |
| EPA/DHA | EPA+DHAで約1g | **魚が週2回以下の週だけ**、朝食と一緒に |

| 変更 | やり方 |
|---|---|
| −150kcal | 昼のご飯 −50g＋夜のご飯 −50g（−156kcal） |
| +150kcal | 夜のご飯を +100g（+156kcal） |
| 約−250kcal（最大） | 昼・夜のご飯を −50g ずつ（−156）＋アーモンドなし（−91） |
| 下限 | **1,700kcal** |
