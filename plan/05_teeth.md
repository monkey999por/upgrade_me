# 05 歯並び（出っ歯）

## 契約ルール（自費の矯正・美容医療）
1. **相談・カウンセリング当日に高額な契約・回数券・コースを契約しない**
2. 見積書と契約書面を受け取る。総額・追加費用・キャンセル時の返金条件を確認する
3. 期間1ヶ月超・5万円超の美容医療は、書面を受け取ってから8日間クーリングオフできる
4. 困ったら **消費者ホットライン 188**
5. 口コミは星の数でなく、悪い口コミの中身（押し売り・説明不足・追加料金）を見る

## 基礎知識
| | ワイヤー（表側） | 裏側・ハーフリンガル | マウスピース |
|---|---|---|---|
| 仕組み | 歯の表面にブラケットを**接着**し、ワイヤーを通す（歯に穴は開けない） | 同じ装置を歯の裏側に。ハーフリンガルは上だけ裏側 | 少しずつ形の違う透明な装置を1–2週間ごとに替える。歯に小さな突起（アタッチメント）をつけることが多い |
| 外せるか | 自分では外せない（24時間） | 同じ | 外せる。ただし1日20–22時間つける。外している間は歯が戻ろうとする |
| 見た目 | 目立つ | ほぼ見えない | 目立ちにくい |
| 痛み | 調整後の数日、歯が浮く・噛むと痛い。装置が頬に擦れて口内炎 | 舌に当たる・発音に慣れが要る | 交換直後に締め付けられる感じ |
| 向いている | 大きく・複雑に動かす。サボれない | ワイヤーが向くが見た目が嫌な場合。高い | 見た目・食事・歯磨きが楽。苦手な動きもある |

- どれが上ということはない。精密検査（横顔のレントゲン＝セファロなど）で「どの歯をどう動かすか」を決めてから装置を選ぶ
- 成人の全体矯正は総額80–120万が目安。通常の矯正は保険外
- 期間は装置をつけて2–3年（20歳以上は3年近くになりやすい）、外したあと保定（リテーナー）1–3年

## 自分の歯の状態（相談前の見立て）
- 上の前歯が下の前歯に**縦に深く被さっている** → **過蓋咬合（ディープバイト）**の可能性。確定は精密検査で
- 深い被さりの治し方は3つの組み合わせ：①前歯を歯茎側へ沈める（圧下）、②前歯の傾きを変える、③奥歯を少し伸ばす（挺出）
- ③が中心だと下あごが下・後ろに回り、**顔が縦に長く、あごが引っ込む方向**に働く。①が中心なら顔の長さはほぼ変わらず、下あごが前に回ってあごが出る方向にも働く
- 過蓋咬合はワイヤーでもマウスピースでも治療の対象になりうる

## 相談で伝えること
- 気になっていること：上の前歯が下の前歯に深く被さっている／出っ歯・口元／あごがない横顔
- **顔を縦に長くしたくない。あごが引っ込むのは避けたい**
- 装置はマウスピースありきでなく、仕上がりがいいほうを選んでほしい
- 11/22までに装置をつけて始めたい（最短の進め方を知りたい）

## 相談で聞くこと
- 私の噛み合わせの問題は何か（過蓋咬合・出っ歯・骨格）。原因は**歯の傾き**か**あごの骨格**か
- 深い被さりは前歯の圧下と奥歯の挺出のどちらで治すか。**下あごが回って顔が長くなる・あごが引っ込む見込みはあるか**
- 抜歯が必要か、なぜか
- ワイヤーとマウスピースのどちらもできるか。**それぞれで仕上がりに差があるか**。期間と総額は
- 横顔（口元・あご）はどう変わる見込みか
- 保定まで含めた総額と追加費用。保定の期間
- 支払い方法（分割・医療費控除の対象になるか）

## 進め方（最短で始める。治療自体は8週間のあとも続く）
治療は1–3年＋保定1–3年。通院は4–8週間に1回。
