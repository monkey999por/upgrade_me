# 05 歯並び（出っ歯）

## 契約ルール（自費の矯正・美容医療）
1. **相談・カウンセリング当日に高額な契約・回数券・コースを契約しない**
2. 見積書と契約書面を受け取る。総額・追加費用・キャンセル時の返金条件を確認する
3. 期間1ヶ月超・5万円超の美容医療は、書面を受け取ってから8日間クーリングオフできる
4. 困ったら **消費者ホットライン 188**
5. 口コミは星の数でなく、悪い口コミの中身（押し売り・説明不足・追加料金）を見る

## 相談で聞くこと
- 出っ歯の原因は **歯の傾き**か **あごの骨格**か（骨格ならマウスピースは向かないことがある）
- 抜歯が必要か
- ワイヤー（表側・裏側）とマウスピースのどれが適しているか、それぞれの期間と総額
- 「あごがない」見た目は、矯正で口元が下がるとどう変わる見込みか
- 治療後の保定期間（後戻りを防ぐ装置を使う期間）と費用
- 支払い方法（分割・医療費控除の対象になるか）

## 進め方（最短で始める。治療自体は8週間のあとも続く）
治療は1–3年＋保定1–3年。通院は4–8週間に1回。

| 順番 | やること | 期間の目安 | 早めるコツ |
|---|---|---|---|
| 1 | 矯正歯科2–3院の初診相談を予約。**並行して一般歯科で虫歯チェックとクリーニング** | すぐ | 虫歯を先に治しておく |
| 2 | 初診相談（2–3院）。一番納得できた院で**精密検査を予約** | 予約から1週間ほど | 相談の予約時に「相談と同じ日に精密検査まで受けられるか」を聞く |
| 3 | 精密検査 | 相談と同じ週〜翌週 | |
| 4 | 治療計画の説明 → **1週間考えてから契約** | 検査の1–3週間後 | 治療費・支払い方法・通院頻度・装置をその日に確定させる |
| 5 | 前処置（抜歯が必要な場合など） | 契約後 | |
| 6 | **ワイヤー矯正**：装着 | 契約後1–2週間 | |
| | **マウスピース矯正**：装着 | スキャンから3週間〜1ヶ月半 | 精密検査のときにスキャンまで済ませられるか聞く |

- 判定日の目標：装置をつけているか、開始日が決まっている
- Before/Afterは口を閉じた横顔で比べる（装置が写っても気にしない）
- マウスピースは1日20–22時間つける
- 歯科医師が関わらない通販のマウスピース矯正は使わない
