# 05 歯並び（出っ歯）

## 契約ルール（自費の矯正・美容医療）
1. **相談・カウンセリング当日に高額な契約・回数券・コースを契約しない**
2. 見積書と契約書面を受け取る。総額・追加費用・キャンセル時の返金条件を確認する
3. 期間1ヶ月超・5万円超の美容医療は、書面を受け取ってから8日間クーリングオフできる
4. 困ったら **消費者ホットライン 188**
5. 口コミは星の数でなく、悪い口コミの中身（押し売り・説明不足・追加料金）を見る

## 基礎知識
| | ワイヤー（表側） | 裏側・ハーフリンガル | マウスピース |
|---|---|---|---|
| 仕組み | 歯の表面にブラケットを**接着**し、ワイヤーを通す（歯に穴は開けない） | 同じ装置を歯の裏側に。ハーフリンガルは上だけ裏側 | 少しずつ形の違う透明な装置を1–2週間ごとに替える。歯に小さな突起（アタッチメント）をつけることが多い |
| 外せるか | 自分では外せない（24時間） | 同じ | 外せる。ただし1日20–22時間つける。外している間は歯が戻ろうとする |
| 見た目 | 目立つ | ほぼ見えない | 目立ちにくい |
| 痛み | 調整後の数日、歯が浮く・噛むと痛い。装置が頬に擦れて口内炎 | 舌に当たる・発音に慣れが要る | 交換直後に締め付けられる感じ |
| 向いている | 大きく・複雑に動かす。サボれない | ワイヤーが向くが見た目が嫌な場合。高い | 見た目・食事・歯磨きが楽。苦手な動きもある |

- どれが上ということはない。精密検査（横顔のレントゲン＝セファロなど）で「どの歯をどう動かすか」を決めてから装置を選ぶ
- 成人の全体矯正は総額80–120万が目安。通常の矯正は保険外
- 期間は装置をつけて2–3年（20歳以上は3年近くになりやすい）、外したあと保定（リテーナー）1–3年

### 抜歯と非抜歯
- 歯を並べるすき間の作り方：①歯を抜く（小臼歯）、②奥歯を後ろへ動かす（歯ぐきに小さなネジ＝アンカースクリューを入れて引く。1本2–3万）、③歯の横を少し削る、④歯列を広げる、⑤親知らずだけ抜く
- 出っ歯・口元が出ている場合、抜かずに無理に並べると**前歯がかえって前に出て口元が出る**。後戻りもしやすい
- 「絶対抜かない」を売りにする医院ではなく、**抜歯案と非抜歯案の両方を、横顔の変化つきで比べて説明してくれる医院**を選ぶ

### 部分矯正
- 前歯など一部だけ動かす。矯正歯科でできる。ワイヤーとマウスピースの両方がある
- 費用は全体矯正より安い（こかい11–60.5万、ファミリア11–33万）。期間も短いことが多い
- 向いている：前歯の軽いガタつき・すき間で、**噛み合わせに大きな問題がない**
- 向かない：過蓋咬合・出っ歯・受け口・奥歯を含む噛み合わせのずれ・スペースが大きく足りない
- 自分は過蓋咬合の可能性があるので、**全体矯正を勧められるかもしれない**。できるかは精密検査で決まる

### 10–50万円の矯正
- 中身は、部分矯正／動かす量が少ない人向けのマウスピースのコース／「○○万円〜」「月々○千円」の表示（検査・調整・保定が別で、総額は高くなりがち）／通販マウスピース（使わない）
- 噛み合わせ・横顔を変えるには全体矯正が要るので、**自分には当てはまらない可能性が高い**。比べるのは毎月の額でなく、保定までの総額
- 例外：骨格が原因で、あごの手術を組み合わせると診断されたら保険が使えて、自費よりかなり安くなることが多い（指定を受けた医院だけ）

## 自分の歯の状態（相談前の見立て）
- 上の前歯が下の前歯に**縦に深く被さっている** → **過蓋咬合（ディープバイト）**の可能性。確定は精密検査で
- 深い被さりの治し方は3つの組み合わせ：①前歯を歯茎側へ沈める（圧下）、②前歯の傾きを変える、③奥歯を少し伸ばす（挺出）
- ③が中心だと下あごが下・後ろに回り、**顔が縦に長く、あごが引っ込む方向**に働く。①が中心なら顔の長さはほぼ変わらず、下あごが前に回ってあごが出る方向にも働く
- 過蓋咬合はワイヤーでもマウスピースでも治療の対象になりうる
- **下の前歯が上の歯ぐきに当たる**ほど深い → 見た目だけでなく、歯ぐきを守るためにも治す意味がある
- 深い被さり＋「あごがない」横顔 → 下あごが後ろにある骨格の可能性。セファロで分かる
- 口を開けるとあごがカクっとなる → 噛み合わせを変える前に、あごの関節も診てもらう
- 下の親知らず（埋まっている）を抜くと、奥歯を後ろへ動かすすき間になり、小臼歯の抜歯が減るかもしれない

### 口元を下げると顔は長くなるか
- 口元を下げる（前歯を後ろへ引く）のは前後の動きなので、それだけでは長くならない。唇が下がり、**あごは相対的に前に出て見える**
- 長くなるかは、深い被さりを**奥歯を伸ばして**治すか、**前歯を沈めて**治すかで決まる。抜歯そのものは主な原因ではない
- 過蓋咬合で前歯を後ろへ引くと、前歯が内側に倒れて被さりが深くなりやすい。前歯を沈める力を同時にかける（アンカースクリューを使うことが多い）
- 下げすぎると口元がくぼんで老けて見える。どこまで下げるかは横顔の予測を見て決める

## 相談で伝えること
- 気になっていること：上の前歯が下の前歯に深く被さっている／出っ歯・口元／あごがない横顔
- 一番よくしたいのは**横顔（口元・あご）**
- **顔を縦に長くしたくない。あごが引っ込むのは避けたい**
- 抜歯は必要ならする（できれば少なく）
- 装置は表側ワイヤーでいい。仕上がりがいいほうを選んでほしい
- 予算は保定まで含めて総額100万くらい
- あごの手術を組み合わせる方法は、話を聞いてから考える
- 下の前歯が上の歯ぐきに当たる。口を大きく開けるとあごが少しカクっとなる
- 上の親知らずは抜いてある。下は埋まっている
- 虫歯がありそう（一般歯科で治療中／予定）
- 通院は平日の夜・土日がいい
- 11/22までに装置をつけて始めたい（最短の進め方を知りたい）

## 相談で聞くこと
- 私の噛み合わせの問題は何か（過蓋咬合・出っ歯・骨格）。原因は**歯の傾き**か**あごの骨格**か
- **口元を下げて、深い被さりは前歯を沈めて治し、奥歯は伸ばさない計画にできるか。横顔と顔の長さがどう変わるか、セファロで予測を見せてもらえるか**
- 抜歯が必要か、なぜか。何本か。下の親知らずを抜いて奥歯を後ろへ動かせば、抜く本数を減らせるか
- 前歯の部分矯正だけで、見た目と噛み合わせの両方を治せるか。全体矯正と比べて仕上がり・期間・総額はどう違うか
- ワイヤーとマウスピースのどちらもできるか。**それぞれで仕上がりに差があるか**。期間と総額は
- あごのカクっという音は、矯正の前に何か必要か
- 保定まで含めた総額と追加費用。保定の期間
- 支払い方法（分割・医療費控除の対象になるか）

## 進め方（最短で始める。治療自体は8週間のあとも続く）
治療は1–3年＋保定1–3年。通院は4–8週間に1回。
