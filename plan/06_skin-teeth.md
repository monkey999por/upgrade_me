# 06 肌（毛穴）と歯並び

## 共通の契約ルール（美容医療・自費の矯正）
美容医療の相談件数は2024年度に1万件を超え、「今日契約すれば安い」と当日契約を迫るトラブルが増えている（国民生活センター）。
1. **カウンセリング当日に回数券・コース・高額な契約をしない**。「今日だけの割引」は断る理由として扱う。例外：ダーマペンの**1回分（トライアル・単発）**だけは、説明に納得できれば当日受けてよい
2. 見積書と契約書面を必ず受け取る。総額・追加費用・キャンセル時の返金条件を確認する
3. 期間1ヶ月超・5万円超の美容医療（脱毛・ニキビ跡やしみの治療など、法律で指定されたもの）は、契約書面を受け取った日から8日間クーリングオフできる（特定商取引法）
4. 困ったら **消費者ホットライン 188**
5. 口コミは星の数でなく、**悪い口コミの中身**（押し売り・説明不足・追加料金）を見る。紹介サイトのランキングは広告の可能性がある

## 肌（毛穴）

### 今日から毎日（自宅ケア）
| タイミング | 手順 |
|---|---|
| 朝 | 洗顔 → 保湿 → **日焼け止め SPF30以上**（紫外線で肌のハリが落ちると毛穴が目立つ） |
| 夜 | 洗顔 → **保湿をしっかり**（ダーマペンの後は肌が乾燥しやすい） |

- **ダーマペンを受ける期間（〜11/22）は、レチノールとピーリング系（サリチル酸・AHAなど）を使わない**。院によって「施術の1週間前後はレチノイン酸・ピーリング剤を控える」「前後3日はレチノールを控える」と指示があり、施術を2–4週間おきに入れると使える日がほとんど残らないため。11/22以降の再開は医師と相談する
- 買ってしまったレチノールは、11/22以降に使う

→ **W1：上の表の上2院をカウンセリング予約**（在宅日の夕方か休日）。スケジュールは下の「ダーマペンの逆算スケジュール」。

### 2院のダーマペンの比較（公式サイトの記載、2026-09-27確認）
| | はなふさ皮膚科 大宮院 | 肌クリニック大宮（毛穴黒ずみダーマペン） |
|---|---|---|
| 料金（税込） | 両頬 トライアル13,200円／両頬＋こめかみ＋鼻 トライアル16,500円／全顔 トライアル22,000円（5回コースもあり）。看護師が施術 | 両頬＋鼻 27,000円／鼻 18,800円／顔全体 28,600円（別に診察料1,500円） |
| 間隔・回数 | 3–8週間おき（はなふさ皮膚科の解説） | 2週間〜1ヶ月おき、1–3回。「2週間おきに3回で効果を実感しやすい」 |
| ダウンタイム | 赤みは数時間〜数日。まれに内出血が出ると消えるまで1–2週間 | 腫れ・赤みは1–3日。内出血が出ると1–2週間 |
| 特徴 | 毛穴の**開き**・ニキビ跡向けの一般的なダーマペン | 毛穴・ニキビ用の薬剤（CLRローション）を塗って行う、**黒ずみ・詰まり**向け |

→ どちらが合うかは、カウンセリングで診断される**毛穴のタイプ**で決まる（黒ずみ・詰まりが中心なら肌クリニック大宮の方式、開きが中心ならはなふさ皮膚科の方式）

### ダーマペンの逆算スケジュール（11/22がゴール）
**逆算のルール**
1. **最後の施術は11/8（日）まで**：内出血が出ると消えるまで1–2週間かかる。毛穴の変化を実感しやすいのは施術の2–4週間後
2. **1回目はできるだけ早く**：肌のコラーゲンが作り直されるのは施術の4–6週間後がピークなので、早く始めるほど11/22に効果が乗る
3. **施術日は在宅日の平日にする**（翌日も在宅日が理想）。日曜の写真撮影の前日（土曜）と、トーストマスターズの前日（10/9・10/23・11/13）は避ける

| 回 | 毛穴の開きが中心（4週間おき） | 黒ずみ・詰まりが中心（2週間おき） |
|---|---|---|
| カウンセリング | **W1（9/29–10/3）** | 同左 |
| 1回目 | **9/30–10/8**（カウンセリング当日でもよい） | 同左 |
| 2回目 | **10/28–11/6**（1回目の4週間後） | 10/13–10/22（1回目の2週間後） |
| 3回目 | 12月（11/22以降も続ける） | 10/27–11/6（2回目の2週間後） |
| 11/22時点 | 2回完了。2回目から2週間以上あけて判定 | 3回完了。3回目から2週間以上あけて判定 |

- **カウンセリング当日に1回だけ受けるのはOK**。回数券・コースはその場で買わない（契約ルールどおり）。1回目の結果を見てから回数券にするか決める
- 毛穴の開きは「1ヶ月おきに3–5回で変化を実感しやすい」という説明が多い → 11/22までに終わらせず、**12月以降もメンテナンスとして続ける**前提で計画する

### 施術の前後に守ること
| 時期 | やること |
|---|---|
| 施術の1週間前〜 | レチノール・ピーリング系を使わない（上のとおり、この期間はずっと使わない） |
| 施術当日 | 院の指示どおり（洗顔・メイクの制限。例：4時間は洗顔しない、24時間はメイクしない、ワセリンで保湿） |
| 当日〜翌日 | 汗をかく激しい運動・サウナ・長風呂・お酒を控える（多くの院で指示される）。**その日の筋トレ・HIITは休み**、ウォーキングだけにする |
| 3日間 | **プール・サウナは入らない**（塩素や熱の刺激を避けるため） |
| ずっと | **日焼け止めを毎日**。施術後の肌に日焼けをすると色素沈着の原因になる |

### カウンセリングで聞くこと
- 自分の毛穴のタイプ（黒ずみ・詰まり／開き／たるみ／ニキビ跡の凹み）はどれか
- 勧める施術と、その理由（ダーマペン・ピコフラクショナル・ニードルRFの違い）
- 1回あたりの料金、推奨回数と間隔、総額
- ダウンタイム（赤み・かさぶたの期間）→ 出社日・Instagramの写真撮影日と重ならないように
- **施術する医師の資格**（皮膚科専門医が施術するのか、看護師か）
- 施術前後に気をつけること（レチノール・日焼け・運動・プール）
- **毛穴のタイプに合わせた間隔（2週間おき or 4週間おき）と、11/8までに何回入れられるか**
- （ついでに）あご下の脂肪・たるみに対して医療でできることと費用。すぐには決めず、W8の減量結果を見てから判断する

→ **W1：専門医以上の資格を持つ医師がいる医院を中心に2–3院を相談予約**（初診相談は無料〜数千円が多い）

### 相談で聞くこと
- 出っ歯の原因は **歯の傾き**か、**あごの骨格**か（骨格が原因ならマウスピースは向かないことがある。日本矯正歯科学会の見解）
- 抜歯が必要か
- ワイヤー（表側・裏側）とマウスピースのどれが適しているか、それぞれの期間と総額
- 「あごがない」見た目は、矯正で口元が下がるとどう変わる見込みか
- 治療後の保定期間（後戻りを防ぐ装置を使う期間）と費用
- 支払い方法（分割・医療費控除の対象になるか）

### 進め方（最短で始める。治療自体は11/22以降も続く）
矯正の流れ：**初診相談 → 精密検査（約90分。レントゲン・歯型・写真）→ 診断（検査の1–3週間後に治療計画の説明）→ 契約 → 虫歯などの前処置 → 装置の装着**。
大人の矯正は、歯を動かす期間が1–3年、そのあと後戻りを防ぐ保定期間が1–3年ほど。通院は4–8週間に1回。

| 時期 | やること | 早めるコツ |
|---|---|---|
| **W1（今週）** | 矯正歯科2–3院の初診相談を予約。**並行して、かかりつけの一般歯科で虫歯チェックとクリーニングを予約** | 虫歯があると矯正の前に治療が必要になり、開始が遅れる。先に済ませておく |
| **W2（10/4–10/10）** | 初診相談（2–3院）。一番納得できた院で**精密検査を予約**（できれば同じ週〜翌週） | 相談の予約時に「相談と同じ日に精密検査まで受けられるか」を聞く |
| W3（10/11–10/17） | 精密検査 | |
| W4–W5（10/18–10/31） | 診断・治療計画の説明 → **1週間考えてから契約** | 説明の日に、治療費・支払い方法・通院頻度・装置の種類をすべて確定させる |
| W5–W6（10/25–11/7） | 前処置（抜歯が必要な場合など） | |
| **W6〜** | **ワイヤー矯正**：契約後1–2週間で装着できることが多い → **11月上〜中旬に開始** | |
| | **マウスピース矯正**：歯型をスキャンしてから装置が届くまで3週間〜1ヶ月半（海外の工場で製造） → **11月下旬〜12月に開始** | 精密検査のときにスキャンまで済ませられるか聞く |

- 11/22時点では「装置をつけて治療が始まっている」か「開始日が決まっている」が目標
- 11/22のBefore/After写真に装置が写っても気にしない（口を閉じた横顔で比べる）

- マウスピース矯正は1日20–22時間の装着が前提で、食事のたびに外す → 間食が自然に減るので減量とは相性がよい
- 歯科医師が関わらない通販のマウスピース矯正は使わない（日本矯正歯科学会が「非常に危険」と注意喚起）
