# 06 肌（毛穴）と歯並び

## 共通の契約ルール（美容医療・自費の矯正）
美容医療の相談件数は2024年度に1万件を超え、「今日契約すれば安い」と当日契約を迫るトラブルが増えている（国民生活センター）。
1. **カウンセリング当日に契約・施術しない**。「今日だけの割引」は断る理由として扱う
2. 見積書と契約書面を必ず受け取る。総額・追加費用・キャンセル時の返金条件を確認する
3. 期間1ヶ月超・5万円超の美容医療（脱毛・ニキビ跡やしみの治療など、法律で指定されたもの）は、契約書面を受け取った日から8日間クーリングオフできる（特定商取引法）
4. 困ったら **消費者ホットライン 188**
5. 口コミは星の数でなく、**悪い口コミの中身**（押し売り・説明不足・追加料金）を見る。紹介サイトのランキングは広告の可能性がある

## 肌（毛穴）

### 今日から毎日（自宅ケア）
| タイミング | 手順 |
|---|---|
| 朝 | 洗顔 → 保湿 → **日焼け止め SPF30以上**（紫外線で肌のハリが落ちると毛穴が目立つ） |
| 夜 | 洗顔 → **レチノール**（市販の低濃度品。W1–2は週3回、W3以降は1日おき、赤み・皮むけが出たら回数を減らす）→ 保湿 |
| 週2回 | 鼻の黒ずみが気になるなら、サリチル酸（BHA）配合の洗顔料か化粧水を**レチノールと別の日**に使う |

- 皮膚科で施術を受けるなら、施術前後のレチノール中止期間は医師の指示に従う

### 皮膚科の選び方
**条件**：①日本皮膚科学会の **皮膚科専門医** が在籍（学会公式の[皮膚科専門医MAP](https://www.dermatol.or.jp/spmap/)で確認）、②毛穴・ニキビ跡の施術メニューがある、③料金表を公開している

大宮区で上の①を満たし、公式サイトで毛穴向けの施術を確認できた院（2026-09-27時点）：
| 院 | 場所 | 専門医MAPへの掲載 | 毛穴向けの施術（公式サイトに記載があるもの） |
|---|---|---|---|
| はなふさ皮膚科 大宮院 | 大宮駅西口 徒歩2分 | あり | ダーマペン、フラクショナルレーザー、ポテンツァ、炭酸ガスレーザー、ケミカルピーリング |
| 肌クリニック大宮 | 大宮駅西口（アクロスキューブ大宮5F） | あり（2名） | 毛穴黒ずみダーマペン、ニードルRF、ピコフラクショナル、炭酸ガスフラクショナル |
| 大宮西口皮フ科形成外科 | 大宮駅西口 | あり | 要確認（公式サイトで美容メニューを確認する） |
| 桜木皮膚科 / あづま皮膚科 / ひかりクリニック | 大宮区内 | あり | 要確認（保険診療が中心の可能性。まず公式サイトで美容メニューを確認） |

→ **W1：上の表の上2院をカウンセリング予約**（在宅日の夕方か休日）。W2で比べ、W3に1回目の施術。

### カウンセリングで聞くこと
- 自分の毛穴のタイプ（黒ずみ・詰まり／開き／たるみ／ニキビ跡の凹み）はどれか
- 勧める施術と、その理由（ダーマペン・ピコフラクショナル・ニードルRFの違い）
- 1回あたりの料金、推奨回数と間隔、総額
- ダウンタイム（赤み・かさぶたの期間）→ 出社日・Instagramの写真撮影日と重ならないように
- **施術する医師の資格**（皮膚科専門医が施術するのか、看護師か）
- 施術前後にレチノールや日焼けで気をつけること
- （ついでに）あご下の脂肪・たるみに対して医療でできることと費用。すぐには決めず、W8の減量結果を見てから判断する

## 歯並び（出っ歯）

### 矯正歯科の選び方
**条件**：①日本矯正歯科学会の **認定医以上**（学会公式の[認定医・専門医名簿](https://www.jos.gr.jp/roster)で確認）、②精密検査（レントゲン・歯型）をしてから治療方針を出す、③ワイヤーとマウスピースの両方を扱っている

大宮区・見沼区で名簿に載っている医院（2026年8月時点の名簿、2026-09-27に確認）：
| 医院 | 場所 | 名簿での資格 |
|---|---|---|
| ファミリア歯科矯正 | 大宮区桜木町（ソニックシティビル12F） | 認定医。専門医・研修指導医の資格を持つ医師も在籍 |
| スマイル矯正歯科 | 大宮区吉敷町 | 認定医・専門医・研修指導医 |
| 大宮こかい矯正歯科 | 大宮区仲町 | 認定医・専門医 |
| 大宮SHIN矯正歯科 | 大宮区桜木町 | 認定医（2名） |
| 大宮矯正歯科 | 大宮区宮町 | 認定医 |
| セレーノ矯正歯科 大宮クリニック | 大宮区桜木町 | 認定医 |
| ひらい歯科医院 | 見沼区東大宮 | 認定医（一般歯科と併設） |

※名簿の資格は予約前にもう一度、学会サイトで確認する。車で行くなら浦和区・上尾市にも名簿掲載の医院が複数ある。
→ **W1：専門医以上の資格を持つ医師がいる医院を中心に2–3院を相談予約**（初診相談は無料〜数千円が多い）

### 相談で聞くこと
- 出っ歯の原因は **歯の傾き**か、**あごの骨格**か（骨格が原因ならマウスピースは向かないことがある。日本矯正歯科学会の見解）
- 抜歯が必要か
- ワイヤー（表側・裏側）とマウスピースのどれが適しているか、それぞれの期間と総額
- 「あごがない」見た目は、矯正で口元が下がるとどう変わる見込みか
- 治療後の保定期間（後戻りを防ぐ装置を使う期間）と費用
- 支払い方法（分割・医療費控除の対象になるか）

### 進め方
| 週 | やること |
|---|---|
| W1 | 2–3院を予約 |
| W2 | 相談（聞くことリストで比較） |
| W3 | 1院に絞って精密検査を予約 |
| W4 | 精密検査 |
| W5 | 治療計画の説明 → **その場で決めず1週間考える** |
| W6–8 | 始めるなら契約 → 装置作成 → 装着 |

- マウスピース矯正は1日20–22時間の装着が前提で、食事のたびに外す → 間食が自然に減るので減量とは相性がよい
- 歯科医師が関わらない通販のマウスピース矯正は使わない（日本矯正歯科学会が「非常に危険」と注意喚起）
