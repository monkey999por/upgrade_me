# 04 肌（毛穴）と歯並び

## 共通の契約ルール（美容医療・自費の矯正）
1. **カウンセリング当日に回数券・コース・高額な契約をしない**。例外：ダーマペンの1回分（単発）だけは当日受けてよい
2. 見積書と契約書面を受け取る。総額・追加費用・キャンセル時の返金条件を確認する
3. 期間1ヶ月超・5万円超の美容医療は、書面を受け取ってから8日間クーリングオフできる
4. 困ったら **消費者ホットライン 188**
5. 口コミは星の数でなく、悪い口コミの中身（押し売り・説明不足・追加料金）を見る

| 院 | 場所 | 毛穴向けの施術 |
|---|---|---|
| はなふさ皮膚科 大宮院 | 大宮駅西口 徒歩2分 | ダーマペン、フラクショナルレーザー、ポテンツァ、炭酸ガスレーザー、ケミカルピーリング |
| 肌クリニック大宮 | 大宮駅西口（アクロスキューブ大宮5F） | 毛穴黒ずみダーマペン、ニードルRF、ピコフラクショナル、炭酸ガスフラクショナル |
| 大宮西口皮フ科形成外科 | 大宮駅西口 | 要確認 |
| 桜木皮膚科 / あづま皮膚科 / ひかりクリニック | 大宮区内 | 要確認（保険診療が中心の可能性） |

→ **上の2院をカウンセリング予約**（在宅日の夕方か休日）

### 2院のダーマペンの比較
| | はなふさ皮膚科 大宮院 | 肌クリニック大宮（毛穴黒ずみダーマペン） |
|---|---|---|
| 料金（税込） | 両頬 トライアル13,200円／両頬＋こめかみ＋鼻 トライアル16,500円／全顔 トライアル22,000円（5回コースもあり）。看護師が施術 | 両頬＋鼻 27,000円／鼻 18,800円／顔全体 28,600円（別に診察料1,500円） |

→ カウンセリングで診断される毛穴のタイプで選ぶ

### ダーマペンの間隔と回数（逆算のルール）
1. **最後の施術は最終判定の2週間前まで**
2. **1回目はできるだけ早く**
3. **施術日は在宅日の平日**（翌日も在宅日が理想）。土曜（写真の前日）は避ける

| 回 | 毛穴の開きが中心（4週間おき） | 黒ずみ・詰まりが中心（2週間おき） |
|---|---|---|
| 1回目 | カウンセリング後できるだけ早く（当日でもよい） | 同左 |
| 2回目 | 1回目の4週間後 | 1回目の2週間後 |
| 3回目 | 判定日のあと（続ける） | 2回目の2週間後 |
| 判定日の時点 | 2回完了。2回目から2週間以上あけて判定 | 3回完了。3回目から2週間以上あけて判定 |

- カウンセリング当日に1回だけ受けるのはOK。回数券は1回目の結果を見てから
- 開き型は8週間で終わらせず、12月以降も続ける

### 施術の前後に守ること
| 時期 | やること |
|---|---|
| 施術の1週間前〜 | レチノール・ピーリング系を使わない |
| 施術当日 | 院の指示どおり（洗顔・メイクの制限。例：4時間は洗顔しない、24時間はメイクしない、ワセリンで保湿） |
| 当日〜翌日 | 激しい運動・サウナ・長風呂・お酒を控える。**筋トレ・HIITは休み**、歩くだけ |
| 3日間 | プール・サウナに入らない |
| ずっと | **日焼け止めを毎日** |

### カウンセリングで聞くこと
- 自分の毛穴のタイプ（黒ずみ・詰まり／開き／たるみ／ニキビ跡の凹み）はどれか
- 勧める施術と、その理由（ダーマペン・ピコフラクショナル・ニードルRFの違い）
- 1回あたりの料金、推奨回数と間隔、総額
- ダウンタイム（赤み・かさぶたの期間）
- **施術する医師の資格**（皮膚科専門医が施術するのか、看護師か）
- 施術前後に気をつけること（レチノール・日焼け・運動・プール）
- **毛穴のタイプに合わせた間隔（2週間おき or 4週間おき）と、最後の施術の期限までに何回入れられるか**
- （ついでに）あご下の脂肪・たるみに医療でできることと費用（決めるのは8週間のあと）

## 歯並び（出っ歯）

**条件**：①矯正歯科学会の認定医以上（[認定医・専門医名簿](https://www.jos.gr.jp/roster)）、②精密検査をしてから治療方針を出す、③ワイヤーとマウスピースの両方を扱っている

| スマイル矯正歯科 | 大宮区吉敷町 | 認定医・専門医・研修指導医 |
| 大宮こかい矯正歯科 | 大宮区仲町 | 認定医・専門医 |

| 大宮矯正歯科 | 大宮区宮町 | 認定医 |

→ **専門医以上がいる医院を中心に2–3院を相談予約**（初診相談は無料〜数千円）

### 相談で聞くこと
- 出っ歯の原因は **歯の傾き**か **あごの骨格**か（骨格ならマウスピースは向かないことがある）
- 抜歯が必要か
- ワイヤー（表側・裏側）とマウスピースのどれが適しているか、それぞれの期間と総額
- 「あごがない」見た目は、矯正で口元が下がるとどう変わる見込みか
- 治療後の保定期間（後戻りを防ぐ装置を使う期間）と費用
- 支払い方法（分割・医療費控除の対象になるか）

### 進め方（最短で始める。治療自体は8週間のあとも続く）
治療は1–3年＋保定1–3年。通院は4–8週間に1回。

| 順番 | やること | 期間の目安 | 早めるコツ |
|---|---|---|---|
| 1 | 矯正歯科2–3院の初診相談を予約。**並行して一般歯科で虫歯チェックとクリーニング** | すぐ | 虫歯を先に治しておく |
| 2 | 初診相談（2–3院）。一番納得できた院で**精密検査を予約** | 予約から1週間ほど | 相談の予約時に「相談と同じ日に精密検査まで受けられるか」を聞く |
| 3 | 精密検査 | 相談と同じ週〜翌週 | |
| 4 | 治療計画の説明 → **1週間考えてから契約** | 検査の1–3週間後 | 治療費・支払い方法・通院頻度・装置をその日に確定させる |
| 5 | 前処置（抜歯が必要な場合など） | 契約後 | |
| 6 | **ワイヤー矯正**：装着 | 契約後1–2週間 | |
| | **マウスピース矯正**：装着 | スキャンから3週間〜1ヶ月半 | 精密検査のときにスキャンまで済ませられるか聞く |

- 判定日の目標：装置をつけているか、開始日が決まっている
- Before/Afterは口を閉じた横顔で比べる（装置が写っても気にしない）
- マウスピースは1日20–22時間つける
- 歯科医師が関わらない通販のマウスピース矯正は使わない
