# 05 顔・首・姿勢（フェイスライン）

## まず正直な前提
| 手段 | 2ヶ月で見た目に効くか | 根拠 |
|---|---|---|
| **全身の体脂肪を落とす** | ◎ 主役 | 顔や顎下だけの脂肪を狙って落とす方法はない。顔まわりの変化は全身の減量についてくる |
| **姿勢（頭が前に出る姿勢の改善）** | ○ 写真ではすぐ差が出る | 頭が前に出ると、あご下〜首の角度が鈍くなり二重あごに見える |
| **むくみ対策（塩分・お酒・睡眠）** | ○ 翌朝に差が出る | [04](04_nutrition.md)の塩分・お酒のルール |
| 表情筋トレーニング | △ おまけ | 根拠は中年女性16人・20週の小規模研究のみ（JAMA Dermatol 2018）。ただし害は少なく、滑舌・表情づくりの練習にはなる |
| ミューイング（舌を上あごに押し付け続ける） | ✕ **やらない** | 大人の顎の骨格を変えるという根拠はなく、歯並びを崩すリスクがあるとアメリカ矯正歯科学会が注意喚起。矯正を控えているならなおさら避ける |
| 首を太くする筋トレ（ネックエクステンション等） | ✕ **やらない** | 首が太く見える方向に働く |
| ガムを長時間噛む・硬いものを噛むトレーニング | ✕ **やらない** | エラ（咬筋）が発達して顔が大きく見える方向に働く |

→ 表情筋トレーニングは「これで顔が変わる」ではなく、**①自分の顔を意識して動かす習慣 ②滑舌・表情の練習 ③姿勢リセットのきっかけ** として、毎日の車移動に入れる。

## 車の中のルーティン（毎日・15分＝前半：表情筋7分 → 後半：発声・滑舌8分）
**安全第一**：運転中は前を見たまま、手はハンドルのまま、目を閉じない。首を大きく動かすものは **信号待ち・駐車後だけ**。

### 走行中にやってよいもの（口・舌・声だけ）
| # | 内容 | 回数 | ねらい |
|---|---|---|---|
| 1 | **「あ・い・う・え・お」を大きく口を動かして発声**（1音2秒ずつ） | 10往復 | 口のまわりの筋肉。後半の発声の準備 |
| 2 | **口をすぼめて左右・上下に動かす**：「う」の口で唇を前に突き出し、そのまま右 → 左、上 → 下へゆっくり動かす | 左右10往復・上下10往復 | 口のまわりの筋肉（口輪筋） |
| 3 | **舌回し**：口を閉じて、舌先で歯ぐきの外側を一周。**最初はゆっくり、後半は速く回す** | ゆっくり 右10・左10 → 速く 右10・左10 | 口元・あご下の筋肉 |
| 4 | **ぶくぶく**：口に空気をためて、うがいのように左右の頬・上唇の上・下唇の下へ空気を移動させる | 30秒 × 2 | 頬のまわりの筋肉 |
| 5 | **口角を上げて5秒キープ → 戻す**（歯を見せる笑顔） | 10回 | 笑顔の形を覚える。写真で表情が固くならない |
| → | **後半は [09 滑舌と声の出し方](09_voice-articulation.md) の車メニュー（V1–V8）**：腹式呼吸・リップロール・あごを動かさずに「らりるれろ」・「ろりょろりょ」・あめんぼの歌・早口ことば・1分トーク | 8分 | 滑舌と声 |

### 信号待ち・駐車後だけ
| # | 内容 | 回数 |
|---|---|---|
| 6 | **ヘッドレストあご引き**：背もたれに背中をつけ、あごを軽く引いて後頭部をヘッドレストに5秒押し当てる | 5回 |
| 7 | **上を向いて、あごを突き出す＋舌を鼻へ**：顔を天井に向け、下あごを上へぐっと突き出して3秒 → 戻す。慣れたら、突き出したまま舌先を鼻に近づけるように引き上げて5秒 | 10回（**駐車後のみ**） |

- 7は首を反らすので、めまい・首の痛み・手のしびれが出たら中止。反動をつけず、ゆっくり動かす

### 車に乗るときの姿勢の確認（毎回）
- 座ったら背もたれを少し立て、**後頭部がヘッドレストにつくかどうか**を確認。つかない（頭が前に出ている）なら、座席の位置と背もたれの角度を直す
- ルームミラーを「背筋を伸ばしたときにちょうど見える高さ」に合わせる → 猫背になるとミラーが見づらくなるので、自然に姿勢に気づける

## 毎日の姿勢ケア（5分、在宅日のトレッドミルの前後や入浴後）
| 内容 | 回数 |
|---|---|
| **あご引き（チンタック）**：壁に背中と後頭部をつけ、あごを水平に引いて二重あごを作るように5秒 | 10回 × 2 |
| **胸を開くストレッチ**：ドア枠に前腕をつけて胸を前に出す | 30秒 × 2 |
| **背中の上部を反らす**：丸めたタオルやフォームローラーを肩甲骨の下に置いて仰向け | 1分 |
| ジムの日：フェイスプル（[03](03_training.md)のB）で背中の上部を鍛える | — |

## セルフマッサージ（夜の入浴後・3分）
**位置づけ**：その日のむくみを一時的に取るためのもの。フェイスラインの形そのものを変えるものではない（顔のマッサージの研究は小規模で、効果は一時的という評価）。

| # | 内容 | 回数 |
|---|---|---|
| 1 | **鎖骨まわりをほぐす**：反対側の手の指先で、鎖骨の上のくぼみと下のラインを、内側（のど側）から外側（肩側）へ軽くさする | 左右 各10回 |
| 2 | **鎖骨を押さえてあご下を伸ばす**：片手で鎖骨の下を押さえて皮膚を下に固定し、顔を斜め上に向けて首の前を伸ばす | 左右 各15秒 × 2 |
| 3 | **あご下のラインを指の関節で押す**：軽く握った手の人差し指の第2関節を、あご下の骨のすぐ内側に当て、**あごの先 → あごの角の手前** まで少しずつずらしながら軽く押す（あごの角の下は頸動脈があるので押さない） | 左右 各3往復 |

**なぜ鎖骨なのか**：首の前を覆う薄い筋肉（広頚筋）は、胸と肩の筋肉を覆う膜から始まり、**鎖骨の上をまたいで**下あご・口角までつながっている（StatPearls）。なので、鎖骨を押さえて首の前を伸ばすのは、構造的には理にかなっている。

**安全のためにやらないこと**
- **首の横の、脈が触れるところ（あごの角の下あたり）を強く押したり揉んだりしない**。頸動脈を刺激して血圧が急に下がったり、まれに脳梗塞につながったりした報告がある。首の横は「軽くさする」まで
- 痛いほど押さない。あご下にしこりや押して痛い場所があれば、マッサージせずに受診する

## お店（小顔・フェイスラインのマッサージ）について
**結論：この8週間は通わなくてよい**。お金と時間は、体脂肪を落とすこと・皮膚科・矯正に回す方が見た目への効果が大きい。気分転換やむくみ取りとして行くなら、下の基準で選ぶ。

| 判断 | 内容 | 理由 |
|---|---|---|
| ○ 行ってもよい | リラクゼーションやリンパマッサージとして、**その日のむくみが取れる程度**と説明している店 | 効果が一時的だと正直に言っている |
| ✕ 避ける | 「骨格が変わる」「エラの骨を押し込む」「1回で顔の横幅が数cm縮む」と宣伝している店 | 2016年に消費者庁が、こうした小顔の宣伝をしていたエステ・整体の9事業者に、根拠がないとして措置命令を出している |
| ✕ 避ける | 首をボキッと鳴らすような施術 | 首の施術後のしびれ・脳梗塞などの危害が国民生活センターに報告されている |
| ✕ 避ける | **エステサロンのHIFU（ハイフ）** | やけどや神経の損傷の事故が報告され、消費者安全調査委員会が調査報告を出している。やるなら医療機関で |

- あご下の脂肪やたるみを医療で何とかしたい場合は、皮膚科のカウンセリングで「あご下」についても相談する（[06](06_skin-teeth.md)）。ただし、まず8週間の減量でどこまで変わるかを見てから判断する

## 目元（目を大きく見せる）

### 正直な前提
- **トレーニングで目（まぶたの開き）そのものを大きくする方法はない**。まぶたを上げる筋肉は、鍛えて大きくなるタイプではなく、まぶたの下がりの多くは皮膚や腱のゆるみが原因。「まぶたの運動が下がりを改善する」という研究はない
- 一方で、**「目が小さく見える原因」を取り除く**ことは今日からできる。8週間で効くのはこちら

| 原因 | 対策 | 効き方 |
|---|---|---|
| **朝のまぶたのむくみ** | 塩分・夜遅くの食事・お酒を控える（[04](04_nutrition.md)）、睡眠6時間以上。起きて20–60分動くとむくみは引く → **写真は起床直後に撮らない** | ◎ 翌朝から |
| **顔全体の脂肪** | 全身の減量（まぶた・頬の厚みも一緒に減る） | ○ 数週間 |
| **眉がぼさぼさ・目との距離が離れて見える** | 眉を整える（下の「眉」） | ○ その日から |
| **近視用メガネ**（テレワークの日） | 近視のレンズは目を小さく見せる（度数が−4.00以上だとはっきり分かる）。ソフトコンタクトではほぼ起きない → 下の「メガネとコンタクトの使い分け」 | ◎ その日から |
| **目を細める癖** | 画面や遠くを見るときに目を細めているなら、度数が合っていない可能性。眼科で視力を測る | ○ |
| **無表情で目に力がない** | 目元の表情の練習（下の「目元の表情トレーニング」） | △ 写真・会話での印象 |

### やってはいけないこと
- **目をこすらない、まぶたを強く引っ張らない**（クレンジングでゴシゴシも含む）。まぶたを上げる筋肉の腱を傷め、将来まぶたが下がる原因になりうる
- **おでこ（眉）を持ち上げて目を開ける癖をつけない**。目は開いて見えるが、おでこの横じわが増える。練習では眉を指で押さえて、眉が動かないようにする
- **目を指で押すマッサージはしない**（眼球を圧迫する）。目のまわりは骨の上を軽く触れる程度まで
- **コンタクトを外すときに、まぶたを強く引っ張らない**。まぶたが下がるリスクが特に高いのはハードコンタクト（日本眼科医会）で、ソフトはそれより低いが、毎日の引っ張りはやめておく

### メガネとコンタクトの使い分け（ソフトコンタクト／テレワークの日はメガネ）
| 場面 | どちらにするか |
|---|---|
| **日曜の写真撮影・Instagram** | **コンタクト**（メガネで撮ると、週によって目の大きさが変わって見えて比較できない） |
| カメラをオンにするオンライン会議・プレゼン | **コンタクト**が基本。メガネのままでよいのは、画面越しの印象を気にしなくてよい打ち合わせだけ |
| テレワークでカメラなしの日 | メガネでOK（目を休める日） |
| 次にメガネを作り直すとき | 度数が−4.00以上なら、**薄型（高屈折・非球面）レンズ**にすると目が小さく見えにくい |

- 日曜の自撮り動画（[09](09_voice-articulation.md)）もコンタクトで撮る
- **コンタクトをつけたまま寝ない**（1:00就寝の前、0:00の洗顔のときに外す）。装用時間の上限は処方どおりに

### 目元の表情トレーニング（家で1分。**車では目を閉じるのでやらない**）
効果は「目が大きくなる」ではなく、**写真や会話で目に表情が出る・目を見開く癖をやめる**ためのもの。
| # | 内容 | 回数 |
|---|---|---|
| E1 | **眉を押さえてまばたき**：両手の人差し指で眉を軽く押さえ、目をぎゅっと3秒閉じる → 眉を動かさずに、まぶただけで目をぱっと開いて3秒 | 5回 |
| E2 | **下まぶたを上げる**：まぶしいものを見るように、下まぶただけを少し持ち上げて3秒（上まぶたは開いたまま）→ 戻す | 5回 |
| E3 | **目で笑う**：口を閉じたまま、目元だけで笑顔をつくる（目尻に軽くしわが寄る）。鏡で確認 | 5回 |
| E4 | **遠近ストレッチ**：30cm先の指先と、窓の外の遠くを交互に5秒ずつ見る | 5往復 |

- E3は写真の表情に直結する。**Instagramの写真を撮る前に1回やる**
- E4はデスクワークで目を細める癖・目の疲れ対策（画面作業の合間のトレッドミル休憩のときに）

### 眉
- 眉の形は目の印象を一番大きく変える。**最初に一度、理容室・眉サロンで整えてもらい**、その形を自分で維持する（眉の下のはみ出した毛を抜く・長い毛をカットする程度）
- 眉と目の間の余分な毛を取ると、目と眉の距離が近く見えて、目元がはっきりする
- 細くしすぎない（男性は太めのまっすぐな眉の方が自然）

## 週1回の計測（日曜の朝）
### 首回り（メジャーで1分）
1. 鏡の前にまっすぐ立ち、**正面を見る**（あごを引いたり上げたりしない）。肩の力を抜く
2. メジャーを **のど仏のすぐ下** に当て、首に対して水平に一周させる（鏡で後ろ側が下がっていないか確認）
3. **肌に沿わせるだけで、締めつけない**（指1本がぎりぎり入らない程度）。息を普通に吐いたところで目盛りを読む
4. 2回測って平均を記録。毎回、**同じ時間帯（日曜の朝、起床後）** に測る

### 横顔写真（あご下の変化はこれで見る）
- 角度は測らない。**毎週同じ条件で撮った横顔を、Day1と並べて比べる**
- 条件：同じ場所・同じ照明、スマホは三脚か棚に置いて **目の高さ**、壁からの距離も同じ。**まっすぐ前を見た自然な姿勢**（あごを引いたり上げたりしない。上を向くとあご下はいつもシャープに写ってしまう）
- **起床後1時間以上たってから撮る**（朝いちばんはまぶた・顔がむくんでいる）。撮る直前に目元の表情トレーニングのE3を1回
- 撮ったらそのままInstagramに投稿（下の「Instagramの運用」）

→ 首回りの数値は weekly_review.md に記入

## Instagramの運用
- 写真の記録場所は **Instagramの匿名アカウント** にする（別で整理はしない）
- 毎週日曜：正面・横・背面・横顔の4枚をまとめて1投稿。キャプションに「W○ / 7日平均○kg / ウエスト○cm / 首回り○cm」
- 公開前に確認：**位置情報はオフ**、背景に住所・勤務先・郵便物・窓の外の景色などが写っていないか。顔を出すかどうかは自分で決める（匿名を保つなら、横顔は目元をスタンプで隠すだけでもあご下の変化は見える）
- **元の写真はスマホのカメラロールに残しておく**（Instagramは投稿時に画像を圧縮・切り抜きするので、最終判定のBefore/Afterは元の写真で作る。アカウントが使えなくなったときの保険にもなる）
