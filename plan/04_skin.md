# 04 肌

## 今日から毎日（自宅ケア）
| タイミング | 手順 |
|---|---|
| 朝 | ぬるま湯で洗う（ベタつく日は洗顔料） → 保湿 → **日焼け止め** |
| 夜 | **洗顔料で洗顔（風呂に入らない日も必ず）** → 保湿 |
| ジムの後 | 汗をぬるま湯で流す（洗顔料は1日2回まで） |

- 洗顔：洗顔料をよく泡立てて、泡で包むように。こすらない。熱いお湯は使わない。タオルは押さえて拭く
- 保湿：洗顔後すぐ、肌が少し湿っているうちに
- 枕カバーは週1回以上替える
- 新しい製品は1つずつ足す（合わなかったときに原因がわかる）
- レチノールは下の「レチノール」、ダーマペンは[12月以降検討](12月以降検討.md)

## 何を揃えるか（化粧水は必須ではない）
| 役割 | 必要？ | 選び方 |
|---|---|---|
| 洗顔料 | 必須 | 洗浄力がマイルドなもの（「弱酸性」「アミノ酸系」など）。スクラブ入りは使わない |
| 化粧水 | **なくてよい** | 水分を足すだけで、油分がないとすぐ蒸発する。使うなら保湿剤の前に |
| 保湿（乳液・ジェル・クリーム） | 必須 | 1本で済ませてよい。**「ノンコメドジェニックテスト済み」**、成分にグリセリン・セラミドなど。脂っぽい肌なら乳液かジェル |
| 日焼け止め | 必須 | **SPF30以上・PA+++以上**、「石けん（洗顔料）で落とせる」と書いてあるもの。保湿と一体型でもよい |

- 日焼け止めの量：顔全体でパール粒2つ分を2回に分けて重ねる。少ないと表示どおりの効果が出ない
- 屋外に長くいる日は2–3時間おきに塗り直す（在宅の日は朝1回でよい）

## レチノール
### 使い方
1. 夜、洗顔 → 保湿のあとに薄く（パール粒1つ分を顔全体）。目のまわり・口角・小鼻のきわは避ける
2. 回数は少しずつ増やす：最初の2週間は週3回（月・水・金）→ 次の2週間は土曜以外の週5回 → そのあとは土曜以外の毎晩
3. **土曜の夜は使わない**（日曜の写真の前夜）
4. 始めて2–4週間は赤み・皮むけ・ヒリヒリが出やすい。強ければ1つ前の回数に戻す
5. 日焼け止めを毎日
6. サリチル酸・ピーリングと同じ日に重ねない。**眉・顔のワックスの2–5日前からは使わない**（毛と一緒に皮膚がはがれやすい）。眉サロンでは「レチノールを使っている」と伝える
7. ヒゲ脱毛・ダーマペンの前後は院の指示どおり止める（目安は施術の1週間前から）
8. **判定は始めて12週間後**：写真を開始時と比べる。足りなければダーマペン（[12月以降検討](12月以降検討.md)）

### 毛穴のタイプ（判定のときに見る）
| タイプ | 見た目 | 主な原因 | レチノールで |
|---|---|---|---|
| 詰まり・黒ずみ | 小鼻・Tゾーンのぽつぽつ。黒いのは詰まった皮脂の酸化 | 皮脂＋古い角質 | よく効く |
| 開き | 頬などで丸く開いて見える | 皮脂が多い（男性ホルモン・遺伝） | ある程度効く |
| たるみ | 頬で縦長・しずく形 | 年齢・乾燥・紫外線 | ある程度効く（日焼け止めも） |
| ニキビ跡の凹み | 頬のクレーター | 炎症で真皮が傷ついた | **ほぼ治らない** → ダーマペンなど |

- 毛穴を押し出す・パックで引き抜くのはしない（広がる・炎症の原因）

### レチノールの種類
| 種類 | 表示名 | 強さ |
|---|---|---|
| レチノール誘導体 | パルミチン酸レチノール・酢酸レチノールなど | 穏やか。初めてならここから（例：無印良品の0.1%美容液） |
| 純粋レチノール | レチノール | 誘導体より強い。医薬部外品の「シワ改善」成分 |
| 処方薬（アダパレン） | ディフェリンゲル | ニキビ・詰まりに保険で出る。皮膚科で相談 |

### 次に足すなら
- **ナイアシンアミド**：皮脂を減らす・毛穴の目立ち・肌荒れ防止。刺激が少ない。レチノールに慣れてから（毎晩使えるようになってから）朝に足す
- ビタミンC：シミ・くすみ。純粋なビタミンCは不安定、誘導体は穏やかだが研究は少ない

### スキンケアの順番（全部使う場合）
洗顔 → 化粧水 → 美容液（有効成分） → 乳液・クリーム → 日焼け止め（朝だけ）

## ヒゲ脱毛（医療レーザー）
### 進め方
1. 下の院から2院のカウンセリングを予約する（無料）
2. 契約は[05の契約ルール](05_teeth.md)どおり。**まず少ない回数・都度払いで1–2回受けて**、痛み・効果・予約の取りやすさを見てから回数の多いコースを決める
3. 照射は1–2ヶ月おき。ヒゲは5–10回以上かかる（濃さで変わる）。ダーマペンをやるなら照射と2週間以上空けて交互に

### 院
| 院 | 場所 | 料金（税込） | 特徴 |
|---|---|---|---|
| 肌クリニック大宮 | 大宮駅西口（アクロスキューブ大宮5F） | 1回：口囲 13,000円／頬＋口囲 または あご下・首＋口囲 16,000円／全体 19,800円（2ヶ月以内の次の回は5%引き）。麻酔込み、初診料1,500円 | 皮膚科。ダーマペンも同じ院でできて、間隔を合わせやすい。回数が多いと割高 |
| メンズリゼ 大宮院 | 大宮駅東口 徒歩4分 | 3部位 5回 14,000円／全部位 5回 59,800円・10回 99,800円。麻酔クリーム 3,300円 | 男性専門の医療脱毛。3部位5回が安くて試しやすい |
| ゴリラクリニック 大宮院 | 大宮駅 徒歩9分 | 3部位 3回 9,800円（10/31までの割引、通常16,800円）／3部位 完了コース6回 35,820円／6部位 6回 69,120円。初回の麻酔は無料 | 男性専門の医療脱毛 |

- 3部位はふつう「鼻下・あご・あご下」。院ごとに範囲が違うのでカウンセリングで確認
- 青ヒゲが気になるのは鼻下・あご。頬・首まで要るかは1–2回やってから決めてよい

### カウンセリングで聞くこと
- 3部位・全部位の範囲（頬・もみあげ・首は入るか）
- 機種と、自分のヒゲの濃さだと何回くらいか
- 追加でかかるお金：麻酔・剃り残しのシェービング・キャンセル料・肌トラブル時の診察や薬
- コースの有効期限、次の予約が何週間先まで埋まっているか
- レチノールはいつから止めればいいか、照射の後いつから使っていいか
- 照射の当日・翌日の運動・入浴・飲酒の制限

### 照射の前後に守ること
| 時期 | やること |
|---|---|
| ずっと | 日焼けしない（日焼けした肌には照射できないことがある）。自己処理は電気シェーバーだけ（**毛抜き・ワックスはしない**。毛根がないとレーザーが効かない） |
| 前日〜当日 | 院の指示どおりに剃っておく |
| 当日 | 汗をかく運動・サウナ・長風呂・お酒は控える。照射は**木曜（筋トレの休み）**か、筋トレのあとに入れる |
| 2–3日 | 赤み・ぽつぽつ（毛のう炎）が出ることがある。**金・土の照射は避ける**（日曜の写真に出る） |
