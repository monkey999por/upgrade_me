# 04 肌

## 今日から毎日（自宅ケア）
| タイミング | 手順 |
|---|---|
| 朝 | ぬるま湯で洗う（ベタつく日は洗顔料） → 保湿 → **日焼け止め** |
| 夜 | **洗顔料で洗顔（風呂に入らない日も必ず）** → 保湿 |
| ジムの後 | 汗をぬるま湯で流す（洗顔料は1日2回まで） |

- 洗顔：洗顔料をよく泡立てて、泡で包むように。こすらない。熱いお湯は使わない。タオルは押さえて拭く
- 保湿：洗顔後すぐ、肌が少し湿っているうちに
- 枕カバーは週1回以上替える
- 新しい製品は1つずつ足す（合わなかったときに原因がわかる）
- レチノールは下の「レチノール」、ヒゲ脱毛は[07](07_hair-removal.md)、ダーマペンは[12月以降検討](12月以降検討.md)

## 何を揃えるか（化粧水は必須ではない）
| 役割 | 必要？ | 選び方 |
|---|---|---|
| 洗顔料 | 必須 | 洗浄力がマイルドなもの（「弱酸性」「アミノ酸系」など）。スクラブ入りは使わない |
| 化粧水 | **なくてよい** | 水分を足すだけで、油分がないとすぐ蒸発する。使うなら保湿剤の前に |
| 保湿（乳液・ジェル・クリーム） | 必須 | 1本で済ませてよい。**「ノンコメドジェニックテスト済み」**、成分にグリセリン・セラミドなど。脂っぽい肌なら乳液かジェル |
| 日焼け止め | 必須 | **SPF30以上・PA+++以上**、「石けん（洗顔料）で落とせる」と書いてあるもの。保湿と一体型でもよい |

- 日焼け止めの量：顔全体でパール粒2つ分を2回に分けて重ねる。少ないと表示どおりの効果が出ない
- 屋外に長くいる日は2–3時間おきに塗り直す（在宅の日は朝1回でよい）

## レチノール
### 使い方
1. 夜、洗顔 → 保湿のあとに薄く（パール粒1つ分を顔全体）。目のまわり・口角・小鼻のきわは避ける
2. 回数は少しずつ増やす：最初の2週間は週3回（月・水・金）→ 次の2週間は土曜以外の週5回 → そのあとは土曜以外の毎晩
3. **土曜の夜は使わない**（日曜の写真の前夜）
4. 始めて2–4週間は赤み・皮むけ・ヒリヒリが出やすい。強ければ1つ前の回数に戻す
5. 日焼け止めを毎日
6. サリチル酸・ピーリングと同じ日に重ねない。**眉・顔のワックスの2–5日前からは使わない**（毛と一緒に皮膚がはがれやすい）。眉サロンでは「レチノールを使っている」と伝える
7. [ヒゲ脱毛](07_hair-removal.md)・ダーマペンの前後は院の指示どおり止める（目安は施術の1週間前から）
8. **判定は始めて12週間後**：写真を開始時と比べる。足りなければダーマペン（[12月以降検討](12月以降検討.md)）

### 毛穴のタイプ（判定のときに見る）
| タイプ | 見た目 | 主な原因 | レチノールで |
|---|---|---|---|
| 詰まり・黒ずみ | 小鼻・Tゾーンのぽつぽつ。黒いのは詰まった皮脂の酸化 | 皮脂＋古い角質 | よく効く |
| 開き | 頬などで丸く開いて見える | 皮脂が多い（男性ホルモン・遺伝） | ある程度効く |
| たるみ | 頬で縦長・しずく形 | 年齢・乾燥・紫外線 | ある程度効く（日焼け止めも） |
| ニキビ跡の凹み | 頬のクレーター | 炎症で真皮が傷ついた | **ほぼ治らない** → ダーマペンなど |

- 毛穴を押し出す・パックで引き抜くのはしない（広がる・炎症の原因）

### レチノールの種類
| 種類 | 表示名 | 強さ |
|---|---|---|
| レチノール誘導体 | パルミチン酸レチノール・酢酸レチノールなど | 穏やか。初めてならここから（例：無印良品の0.1%美容液） |
| 純粋レチノール | レチノール | 誘導体より強い。医薬部外品の「シワ改善」成分 |
| 処方薬（アダパレン） | ディフェリンゲル | ニキビ・詰まりに保険で出る。皮膚科で相談 |

### 次に足すなら
- **ナイアシンアミド**：皮脂を減らす・毛穴の目立ち・肌荒れ防止。刺激が少ない。レチノールに慣れてから（毎晩使えるようになってから）朝に足す
- ビタミンC：シミ・くすみ。純粋なビタミンCは不安定、誘導体は穏やかだが研究は少ない

### スキンケアの順番（全部使う場合）
洗顔 → 化粧水 → 美容液（有効成分） → 乳液・クリーム → 日焼け止め（朝だけ）
