# 02 1日の型（就寝1:00 / 起床7:00、睡眠6時間が下限）

どの日も「共通の朝」と「共通の夜」は同じ。真ん中だけ日の種類で変える。

**→ 毎日やることのチェックリストは [calendar.html](calendar.html) の「今日のTODO」**。その日が筋トレ日・出社日・休日のどれかに合わせて、この表の内容とその日の筋トレメニュー・献立が出る。

## 共通の朝（7:00–7:30）
| 時刻 | やること | 記録 |
|---|---|---|
| 7:00 | 起床 → トイレ → **体重・体脂肪を測る**（服を着ていない状態で） | weight_kg / bodyfat_pct |
| 7:05 | **鏡で正面と横顔を10秒見る**。気になる点を1つだけ言葉にする（例：「今日はむくみが少ない」） | — |
| 7:10 | 洗顔 → 保湿 → 日焼け止め（SPF30以上） | sunscreen |
| 7:15 | 朝食（[04](04_nutrition.md)の朝の型A–Dから1つ）＋サプリ（肉の日はビタミンD。魚が少ない週はEPA/DHA） | — |
| 7:30 | スマートウォッチで前夜の睡眠時間を確認 | — |

## 在宅日
| 時刻 | やること |
|---|---|
| 9:00–12:00 | 仕事。**50分作業 → 10–15分トレッドミル速歩**（5–6km/h、会話できるくらいの息）を2回 |
| 12:00 | 昼食（[04](04_nutrition.md)の献立例 or 入れ替え表から） |
| 13:00–18:00 | 仕事。50分作業 → 10–15分速歩を2回（合計で1日40–60分）。休憩のどこかで家の発声メニュー5分（[09](09_voice-articulation.md)） |
| 15:30 | 間食（[04](04_nutrition.md)の入れ替え表から1つ。基本はプロテイン＋低脂肪乳＋アーモンド。筋トレの日は筋トレ直後に回してよい） |
| 18:30–20:00 | **ジム**（U / L / Push / Pull / Legs を順番に。U・Pushの日は最後にバイクHIIT。[03](03_training.md)）。車での移動中に顔・首＋発声のルーティン15分（[05](05_face-neck-posture.md) → [09](09_voice-articulation.md)） |
| 20:30 | 夕食（筋トレの後なので、ご飯200gはここで食べる） |
| 21:00–0:00 | 作業時間。週1回はここでVRChat 60分（[10](10_social-reps.md)。0:00には必ず終了） |

## 出社日（電車 片道約1時間）
| 時刻 | やること |
|---|---|
| 行き | **話し方トレーニング**（[07](07_inner-speaking.md)）：前半はインプット、後半は今日のネタを起承転結でメモ |
| 昼 | コンビニのセット（[04](04_nutrition.md)）、昼休みに10分歩く |
| 帰り | 会話の振り返り＋Homework for Life（1行） |
| 夜 | 歩数が8,000歩未満なら家のトレッドミルで不足分を歩く。筋トレはしない |

## 休日
| 時刻 | やること |
|---|---|
| 午前 | ジム（その日の分割。在宅日の夕方と同じ内容）。筋トレのない休日は歩行60分 |
| 午後 | 自由。作り置き（日曜・水曜の週2回、約60分） |
| **日曜** | 朝：**週1回の計測**（起床後すぐにウエスト・首回り → 8:00以降に写真4枚。むくみが引いてから撮る）→ Instagram投稿 → **Claudeに週次の報告**（[weekly_review](../tracking/weekly_review.md)）。夜：1分原稿の録音＋ネタを1本2分で話して自撮り → 見返す（[09](09_voice-articulation.md)） |

## 共通の夜（23:30–1:00）
| 時刻 | やること | 記録 |
|---|---|---|

| 0:00 | コンタクトを外す → 洗顔 → 保湿（**〜11/22はレチノールを使わない**。ダーマペンと重ならないように。[06](06_skin-teeth.md)） | — |
| 0:10 | 姿勢ケア5分＋セルフマッサージ3分＋目元の表情1分（[05](05_face-neck-posture.md)）※姿勢ケアは日中に済ませていればスキップ | — |
| 0:30 | **スマホを置く**。照明を落とす | — |
| 1:00 | 就寝 | — |

## 最低限の日（崩れた日の保険）
体調不良・残業などで予定どおりにできない日は、これだけやればOK：
1. 体重を測る
2. 食事をあすけんに入力（ざっくりで可）
3. 日焼け止め
4. 1:00に寝る
