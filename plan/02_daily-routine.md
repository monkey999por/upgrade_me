# 02 ルーティンのやり方

**いつやるか（時刻・曜日・日付）は [calendar.html](calendar.html) にまとめている。** このファイルは、それぞれのルーティンで **何をどうやるか** だけを書く。
- 「毎日のルーティン」タブ：毎日同じこと（下の朝・日中・夜のルーティン）
- 「今日」タブ：その日だけのこと（在宅日・出社日・日曜・ジム）

1日の骨組みは **起床7:00・就寝1:00**。睡眠6時間が下限（[08](08_recovery-rules.md)の#2）。

## 朝のルーティン
| やること | やり方 |
|---|---|
| 体重・体脂肪を測る | 起床 → トイレ → 服を着ていない状態で体組成計に乗る。値はアプリに任せる（手で記録しない） |
| 鏡を見る | 正面と横顔を10秒見る。気になる点を1つだけ言葉にする（例：「今日はむくみが少ない」） |
| スキンケア | 洗顔 → 保湿 → 日焼け止め（SPF30以上）。[06](06_skin-teeth.md) |
| 朝食 | [04](04_nutrition.md)の朝の型A–Dから1つ。肉の日はビタミンD、魚が少ない週はEPA/DHAも一緒に |
| 睡眠の確認 | スマートウォッチで前夜の睡眠時間を見る。6時間未満が週3日になったら08の#2 |

## 日中のルーティン
| やること | やり方 |
|---|---|
| 1万歩 | 在宅日はトレッドミル、出社日は通勤と昼休み。夜の時点で足りなければ家のトレッドミルで不足分を歩く（[03](03_training.md)のウォーキング） |
| 顔・首＋発声 15分 | 車の中で。前半7分は表情筋（[05](05_face-neck-posture.md)）、後半8分は発声・滑舌（[09](09_voice-articulation.md)）。車に乗らない日は家で |
| 自分から話しかける | 雑談・相談・お礼のどれかを1日1回以上（[10](10_social-reps.md)） |
| 間食 | [04](04_nutrition.md)の間食の型から1つ。筋トレの日は筋トレ直後に回してよい |

## 夜のルーティン
| やること | やり方 |
|---|---|
| あすけん確認・翌日の準備 | 食事の入れ忘れがないか、タンパク質170gに届いたかを見る。ジムバッグ・弁当を用意する |
| 洗顔 → 保湿 | コンタクトを外してから。**この8週間はレチノールを使わない**（ダーマペンと重ならないように。[06](06_skin-teeth.md)） |
| 姿勢ケア＋マッサージ＋目元 | 姿勢ケア5分＋セルフマッサージ3分＋目元の表情1分（[05](05_face-neck-posture.md)）。姿勢ケアは日中に済ませていればスキップ |
| スマホを置く | 照明を落とす。VRChatもこの前に必ず終える（[10](10_social-reps.md)） |
| 就寝 | 1:00 |

## 在宅日にやること
| やること | やり方 |
|---|---|
| トレッドミル休憩 | **50分作業 → 15分トレッドミル速歩**を4回（5–6km/h、会話できるくらいの息）。合計60分 |
| 家の発声メニュー | 5分。休憩のトレッドミルの前後などに（[09](09_voice-articulation.md)の「家」） |
| ジム | 夕方。その日の分割（U / L / Push / Pull / Legs）の中身は [03](03_training.md) |
| 夕食 | ご飯100g。炭水化物は筋トレ前の昼に多め（[04](04_nutrition.md)） |
| VRChat | 週1回、夜に60分（[10](10_social-reps.md)） |

## 出社日にやること
電車で片道約1時間。筋トレはしない（休養日）。
| やること | やり方 |
|---|---|
| 行き：話し方トレーニング | 前半はインプット、後半は今日のネタを起承転結でメモ（[07](07_inner-speaking.md)） |
| 昼：コンビニ＋歩く | コンビニのセット（[04](04_nutrition.md)）。昼休みに10分歩く。夜にブロッコリー100gを足す |
| 帰り：振り返り | 会話の振り返り＋Homework for Life（1行）（[07](07_inner-speaking.md)） |

## 日曜にやること
| やること | やり方 |
|---|---|
| 週1回の計測 | 起床後すぐにウエスト・首回り（測り方は[05](05_face-neck-posture.md)）。8:00以降、むくみが引いてから写真4枚（正面・横・背面・横顔）→ Instagram |
| Claudeに週次の報告 | [weekly_review](../tracking/weekly_review.md)の「送るもの」を埋めて送る。来週の出社日を calendar.html で設定する |
| 献立・買い出し・作り置き | 04の入れ替え表から1週間分の献立を決める → 買い出し → 作り置き60分（[04](04_nutrition.md)の作り置き）。水曜にもう1回 |
| 声の記録 | 1分原稿の録音＋ネタを1本2分で話して自撮り → 見返す（[09](09_voice-articulation.md)の「日曜」） |

## 最低限の日
体調不良・残業などで予定どおりにできない日は、これだけやればOK：
1. 体重を測る
2. 食事をあすけんに入力（ざっくりで可）
3. 日焼け止め
4. 1:00に寝る
