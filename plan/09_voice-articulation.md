# 09 滑舌と声の出し方（プレゼンで「いい声」と言われる話し方）

## 目指す状態（8週間後）
| 観点 | 目標 | 測り方 |
|---|---|---|
| 聞き取りやすさ（滑舌） | 固定の文章（下の「1分原稿」）を**噛まずに**読める | 日曜の録音で噛んだ回数を数える |
| 速さ | **1分で約300字**（NHKがニュース原稿の目安にしている速さ） | 1分原稿（約300字）がぴったり1分で読み終わるか |
| 声の響き・安定 | 語尾まで声が消えず、同じ高さ・大きさで言い切れる | 録音で、文の最後の2–3文字がはっきり聞こえるか |
| 間（ま） | 文の区切りで1拍止まり、「えー」「あのー」が1分で2回以下 | 日曜の2分トークの録音で数える |

### 「いい声」の正体
- 研究では、男性は**低めの声**の方が「頼れる・有能」と受け取られやすい（大統領選の討論の分析など）。ただし**無理に低く作った声は喉を痛める**。狙うのは「自分が一番楽に出せる高さの、少し下寄り」
- それより効くのは **①姿勢と呼吸で声が安定していること ②語尾まで言い切ること ③速すぎないこと ④間があること**。この4つは練習で確実に変わる
- 姿勢は [05](05_face-neck-posture.md) のあご引き・胸を開くストレッチとつながっている（頭が前に出ると喉が詰まった声になる）

## プレゼン・会議での話し方のルール（実際の場面で意識するのは3つだけ）
1. **最初の一文は、いつもより少し大きく、ゆっくり**。最初の印象で「落ち着いた声の人」になる
2. **文の最後を下げて言い切る**。「〜と思うんですけど…」とぼかさず「〜です。」で止める。語尾が消えると自信がなく聞こえる
3. **大事な言葉の前で1拍止まる**。「結論は、（間）3つです」。間があると、声そのものが落ち着いて聞こえる

### その他のコツ
- 話す前に **V1の腹式呼吸を2回**（トイレや移動中にできる）
- 「えー」が出そうになったら、**黙って1拍止まる**方に置き換える
- オンライン会議は、マイクに近づいて**普段より少し小さめの声**で話す方が、響きのある声に聞こえる

## 喉を守るルール
| やること / やらないこと | 理由 |
|---|---|
| 水をこまめに飲む | 声帯の表面を潤す（アメリカ言語聴覚協会（ASHA）） |
| 咳払いを繰り返さない → 水を飲むか、つばを飲み込む | 咳払いは声帯同士を強くぶつける |
| ささやき声で長く話さない | ささやき声も喉に負担がかかる |
| 騒がしい場所で声を張り上げない | 喉を痛める一番の原因 |
| お酒は控えめに | 体の水分が失われる（[04](04_nutrition.md)の週1回・2杯までと同じ） |
| 無理に低い声を作らない | 喉が締まって疲れる。練習後に喉が痛い・かすれるなら、その日は中止 |
| **声のかすれが4週間以上続いたら耳鼻咽喉科へ** | 声帯のポリープなどが隠れていることがある。アメリカ耳鼻咽喉科・頭頸部外科学会の診療ガイドラインでも、4週間治らない声がれは喉の検査を勧めている |

## 練習用の文章

### あめんぼの歌（北原白秋「五十音」1922年）
演劇やアナウンサーの発声練習で定番の詩。五十音がバランスよく入っている。
※ Wikisourceの原文を、練習しやすいように現代のかなづかいに直したもの。

```
あめんぼ　あかいな　ア、イ、ウ、エ、オ。
うきもに　こえびも　およいでる。

かきのき　くりのき　カ、キ、ク、ケ、コ。
きつつき　こつこつ　かれけやき。

ささげに　すをかけ　サ、シ、ス、セ、ソ。
そのうお　あさせで　さしました。

たちましょ　らっぱで　タ、チ、ツ、テ、ト。
トテトテ　タッタと　とびたった。

なめくじ　のろのろ　ナ、ニ、ヌ、ネ、ノ。
なんどに　ぬめって　なにねばる。

はとぽっぽ　ほろほろ　ハ、ヒ、フ、ヘ、ホ。
ひなたの　おへやにゃ　ふえをふく。

まいまい　ねじまき　マ、ミ、ム、メ、モ。
うめのみ　おちても　みもしまい。

やきぐり　ゆでぐり　ヤ、イ、ユ、エ、ヨ。
やまだに　ひのつく　よいのいえ。

らいちょうは　さむかろ　ラ、リ、ル、レ、ロ。
れんげが　さいたら　るりのとり。

わい　わい　わっしょい　ワ、イ、ウ、エ、ヲ。
うえきや　いどがえ　おまつりだ。
```
覚える順番：W1＝ア・カ行／W2＝サ・タ行／W3＝ナ・ハ行／W4＝マ・ヤ行／W5＝ラ・ワ行／W6以降＝通しで言う

### 1分原稿（約300字。速さと滑舌のチェック用。毎週同じ文章を読む）
```
本日は、新しい取り組みについてご説明します。結論から申し上げると、ポイントは三つです。
一つ目は、作業時間の短縮です。これまで手作業で行っていた確認を自動化することで、一日あたり約三十分の時間を生み出せます。
二つ目は、品質の向上です。確認の漏れがなくなるため、手戻りが大きく減ると見込んでいます。
三つ目は、チーム全体の見通しがよくなることです。誰が何をしているのかが一目でわかるようになり、相談もしやすくなります。困っている人に早く気づけるので、問題が大きくなる前に手を打てます。
まずは来月から、小さな範囲で試してみたいと考えています。以上、三つのポイントについてご説明しました。ご意見があれば、ぜひお聞かせください。
```
- ちょうど1分で読み終われば約300字/分。50秒より早ければ速すぎ、70秒以上なら遅すぎ
- 読むときに意識すること：「結論から申し上げると、（間）ポイントは三つです」のように、大事な言葉の前で1拍止まる
