# 09 滑舌と声の出し方（プレゼンで「いい声」と言われる話し方）

## 目指す状態（8週間後）
| 観点 | 目標 | 測り方 |
|---|---|---|
| 滑舌 | 1分原稿を**噛まずに**読める | 日曜の録音で噛んだ回数 |
| 速さ | **1分で約300字** | 1分原稿がぴったり1分で読み終わるか |
| 声の安定 | 語尾まで声が消えない | 録音で文の最後の2–3文字が聞こえるか |

- 声の高さは「自分が一番楽に出せる高さの、少し下寄り」。無理に低く作らない

---

## 毎日のメニュー

### 車の中（毎日・後半8分）
[05の表情筋](05_face-neck-posture.md)（前半7分）のあとに続ける。運転中は前を見たまま、手はハンドルのまま。

| # | 内容 | 回数・時間 |
|---|---|---|
| V1 | **腹式呼吸**：鼻から4秒吸ってお腹をふくらませる → 「スーーー」と歯の隙間から8秒で細く長く吐く | 5回 |
| V2 | **リップロール**：唇を軽く閉じて「プルルルル」と震わせながら、低い音 → 高い音 → 低い音へ声を上下させる | 30秒 × 3 |
| V3 | **ハミング**：口を閉じて「んーー」。鼻や唇がビリビリ響く高さを探して、その高さで5秒 | 5回 |
| V4 | **あごを動かさずに「らりるれろ」**（下の※）。最初はゆっくり1音ずつ → 慣れたら速く | ゆっくり5回 → 速く5回 |
| V5 | **「ろりょろりょろりょ…」を繰り返す**（10秒間、音が崩れない一番速いテンポで） | 10秒 × 3 |
| V6 | **「あめんぼの歌」を1段ずつ**（下の本文）。1週間で2段ずつ覚えて、覚えた段だけ言う | 覚えた段を2回 |
| V7 | **早口ことば**：「生麦生米生卵」「東京特許許可局」「赤巻紙青巻紙黄巻紙」をはっきり3回ずつ | 3つ |

※ V4：運転中は奥歯を軽く離した位置であごを止めたまま言う。手であごを押さえるやり方は家で（H2）。

### 家（在宅日に5分。休憩のトレッドミル前後などに）
| # | 内容 | 時間 |
|---|---|---|
| H1 | **ストロー発声**：細いストロー（直径3–5mm）をくわえて「うーー」と声を出し、低い音 → 高い音へサイレンのように上下させる。喉が楽な発声の感覚をつかむ | 2分 |
| H2 | **あごを手で押さえて「らりるれろ」**：片手の親指と人差し指で下あごを軽くつまんで固定し、舌だけで発音 | 1分 |
| H3 | **1分原稿を音読**して、スマホのストップウォッチで時間を測る | 1分 |
| H4 | **ペンを横にくわえて早口ことば** → ペンを外してもう一度（外した後、口が大きく動くのを感じる） | 1分 |

### 日曜（週1回の記録・5分）
1. **1分原稿を読んで録音** → 読み終わった秒数、噛んだ回数、語尾が消えた箇所の数を記録
2. Day1の録音と聴き比べる
3. 数字を週次レビューに入れる

## プレゼン・会議での話し方のルール（実際の場面で意識するのは3つだけ）
1. **最初の一文は、いつもより少し大きく、ゆっくり**
2. **文の最後を下げて言い切る**。「〜と思うんですけど…」ではなく「〜です。」
3. **大事な言葉の前で1拍止まる**。「結論は、（間）3つです」

### その他のコツ
- 話す前に **V1の腹式呼吸を2回**（トイレや移動中にできる）
- 「えー」が出そうになったら、**黙って1拍止まる**方に置き換える
- オンライン会議は、マイクに近づいて普段より少し小さめの声で

---

## 喉を守るルール
- 水をこまめに飲む
- 咳払いを繰り返さない（水を飲むか、つばを飲み込む）
- ささやき声で長く話さない。騒がしい場所で声を張り上げない
- お酒は控えめに
- 無理に低い声を作らない。練習後に喉が痛い・かすれるならその日は中止
- **声のかすれが4週間以上続いたら耳鼻咽喉科へ**

## 練習用の文章

### あめんぼの歌（北原白秋「五十音」1922年）

```
あめんぼ　あかいな　ア、イ、ウ、エ、オ。
うきもに　こえびも　およいでる。

かきのき　くりのき　カ、キ、ク、ケ、コ。
きつつき　こつこつ　かれけやき。

ささげに　すをかけ　サ、シ、ス、セ、ソ。
そのうお　あさせで　さしました。

たちましょ　らっぱで　タ、チ、ツ、テ、ト。
トテトテ　タッタと　とびたった。

なめくじ　のろのろ　ナ、ニ、ヌ、ネ、ノ。
なんどに　ぬめって　なにねばる。

はとぽっぽ　ほろほろ　ハ、ヒ、フ、ヘ、ホ。
ひなたの　おへやにゃ　ふえをふく。

まいまい　ねじまき　マ、ミ、ム、メ、モ。
うめのみ　おちても　みもしまい。

やきぐり　ゆでぐり　ヤ、イ、ユ、エ、ヨ。
やまだに　ひのつく　よいのいえ。

らいちょうは　さむかろ　ラ、リ、ル、レ、ロ。
れんげが　さいたら　るりのとり。

わい　わい　わっしょい　ワ、イ、ウ、エ、ヲ。
うえきや　いどがえ　おまつりだ。
```
覚える順番（1週間に2行ずつ）：ア・カ行 → サ・タ行 → ナ・ハ行 → マ・ヤ行 → ラ・ワ行 → 通しで言う

### 1分原稿（約300字。速さと滑舌のチェック用。毎週同じ文章を読む）
```
本日は、新しい取り組みについてご説明します。結論から申し上げると、ポイントは三つです。
一つ目は、作業時間の短縮です。これまで手作業で行っていた確認を自動化することで、一日あたり約三十分の時間を生み出せます。
二つ目は、品質の向上です。確認の漏れがなくなるため、手戻りが大きく減ると見込んでいます。
三つ目は、チーム全体の見通しがよくなることです。誰が何をしているのかが一目でわかるようになり、相談もしやすくなります。困っている人に早く気づけるので、問題が大きくなる前に手を打てます。
まずは来月から、小さな範囲で試してみたいと考えています。以上、三つのポイントについてご説明しました。ご意見があれば、ぜひお聞かせください。
```
- 50秒より早ければ速すぎ、70秒以上なら遅すぎ
- 大事な言葉の前で1拍止まる
