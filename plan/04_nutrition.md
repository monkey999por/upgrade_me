# 04 食事

## 1日の目標
| 項目 | 目標 | 根拠 |
|---|---|---|
| カロリー | **1,900 kcal** | 維持カロリー（推定2,400–2,500）から約−500〜600 |
| タンパク質 | **150 g** | 除脂肪体重57.6kg × 2.3–3.1g（ISSN）の下限寄り＋α |
| 脂質 | **50–55 g** | 削りすぎない（ホルモン・脂溶性ビタミンのため） |
| 炭水化物 | **残り（約200 g）** | 筋トレの質を保つ。筋トレの日は夕食に寄せる |
| 塩分 | 7.5 g未満を目安 | 顔のむくみ対策（厚労省の男性の目標量） |
| お酒 | 週1回・2杯まで | むくみと食欲増加、睡眠の質低下を避ける |

- 最初の2週間（W1–2）は調整期間。7日平均の落ち方を見て [08](08_recovery-rules.md) でカロリーを確定する
- 記録はすべて **あすけん**（栄養計算が日本食品標準成分表2020年版（八訂）準拠）。自炊はキッチンスケールで量る

### 夜の魚（週2回以上）
- 鮭・ブリ・サバ・サーモン・マグロ（刺身や寿司でOK。加熱しなくてもEPA/DHAはとれる）
- 置き換え方：鶏むね200g → **刺身150g＋ご飯を50g減らす**（サーモンやブリは脂が多いので）
- 寿司の日：サーモン・ブリ・サバ・イワシ・赤身を中心に8–10貫、揚げ物のサイドメニューはなし

### 牛肉・豚肉
- 「避ける」のではなく **赤身（牛もも・豚ヒレ）を週1–2回**、鶏むねの代わりに。亜鉛・鉄・ビタミンB群がとれる
- バラ肉・ひき肉・ベーコンは避ける

## コンビニの日（出社日の昼など）
| セット | 中身 | 目安 |
|---|---|---|
| ① 定番 | サラダチキン1個＋おにぎり1個（鮭など）＋ゆで卵1個＋カップのサラダ（ノンオイルドレッシング） | 約500kcal / P40g |
| ② 麺の気分 | 蕎麦（ざる）＋サラダチキン＋ゆで卵 | 約550kcal / P40g |
| ③ 時間がない | 高たんぱくヨーグルト（ギリシャヨーグルト）＋プロテインドリンク＋おにぎり1個 | 約450kcal / P40g |

- 避けるもの：菓子パン、揚げ物、カップ麺、甘い飲み物、ドレッシング・マヨネーズ（カロリーが見えにくい）

## 外食の日（週1回まで）
- 定食屋：焼き魚定食・生姜焼き（ご飯少なめ）。揚げ物は選ばない
- 焼肉：赤身・ハラミ・タン中心、ご飯小。翌日は固定メニューに戻すだけ（食事を抜いて取り返さない）

## サプリ（食事で足りない分だけ）
| サプリ | 量 | 理由 | 注意 |
|---|---|---|---|
| プロテイン | 1日1–2杯 | タンパク質150gに届かせる | ホエイで十分。高いものは不要 |
| ビタミンD | 25μg（1,000IU）/日 | 魚が少なく屋内中心。目安量は9μg、上限は100μg（厚労省2025年版） | 上限を超える高用量品は避ける |
| EPA/DHA（フィッシュオイル） | EPA+DHAで約1g/日 | 魚をほとんど食べない | **魚を週2回以上食べた週は不要** |
| 亜鉛 | 10mg/日まで | 牛・豚・貝類が少ない食事では不足しやすい（推奨量9mg） | 食事と合わせて上限40mgを超えない。50mgなどの海外の高用量品は避ける |
| ビタミンC | 基本は不要 | キウイ＋ブロッコリーで100mg/日を超える | キウイを食べない日だけ |

- **この8週間は見送るもの**：クレアチン（水分で体重が1kg前後増え、数値の判定が狂うため。W8以降に検討）、コラーゲン（企業からの資金提供がない研究・質の高い研究だけに絞ると効果が見られない）、「美肌」をうたうマルチサプリ
- 飲むタイミング：ビタミンD・EPA/DHAは脂質を含む朝食と一緒に

## 買い物リスト（1週間分・週2回に分けて買う）
- 鶏むね肉（皮なし）：2.8kg（200g × 14食分）※うち2–4食分は魚・赤身に置き換え
- 卵：14個
- 納豆：7パック
- 無糖ヨーグルト：1kg
- 米：約2.8kg分（ご飯換算。炊いて小分け冷凍）
- ブロッコリー：3–4株（冷凍ブロッコリーでOK）
- 葉物野菜（グリーンリーフ等）・トマト・きのこ
- キウイ：7個
- 刺身（鮭・ブリ・サバなど）：2–3回分
- プロテイン（買い置き）

## 作り置き（日曜・水曜、各60分）
1. 鶏むね肉：塩麹やハーブソルトで下味 → 低温調理 or フライパンで蒸し焼き → 200gずつ小分け
2. ご飯：炊いて150g・100gに小分けして冷凍
3. ブロッコリー：茹でる（または冷凍品）
4. ゆで卵：7個
