# 出典と信頼度

信頼度：**A** = 公的機関・学会のガイドラインやメタ解析／**B** = ランダム化比較試験（RCT）／**C** = 総説・観察研究・小規模研究・専門家の見解／**D** = 二次情報（紹介サイト・企業ブログ・まとめ記事）。D は候補探しにだけ使い、判断の根拠にはしない。
