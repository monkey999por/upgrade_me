# 07 話し方トレーニング（出社日の電車・片道約1時間）

目標：**起承転結のある2分の話を、8週間で8本ストックして日常会話で使う**。
電車では書く・振り返る。声に出すのは車の中（[09](09_voice-articulation.md)のV8）と日曜の自撮り。

## 教材
| 教材 | 学べること |
|---|---|
| 『1分で話せ』伊藤羊一 | 結論 → 根拠 → 例の順で短く伝える型 |
| "Storyworthy" Matthew Dicks（英語。Audibleあり） | 日常の出来事を面白い話にする方法。**Homework for Life**（毎日1行、話になりそうな出来事を記録する） |

- 英語が負担なら[要約記事](https://aliabdaal.com/book-notes/storyworthy-matthew-dicks-summary-and-notes/)で要点だけ
- 動画でプロの話を聞くときは、どこで流れが変わったか・オチの前に何を仕込んでいたかを見る

## 行き（60分）
| 分 | やること |
|---|---|
| 0–30 | 教材を読む／聞く。「使えそうな型」を1つだけメモ |
| 30–50 | 今日のネタを1本、4行で書く（下のテンプレ） |
| 50–60 | 今日の会議・雑談で、そのネタか型を使う場面と、話しかける相手を1つ決める |

### ネタの4行テンプレ（起承転結）
```
起：いつ・どこで・誰と
承：何をしようとしていたか／何を期待していたか
転：予想と違ったこと・自分の中で何かが変わった瞬間 ← 話の核
結：それで自分はどう変わったか（オチ or 一言）
```
- ネタの元は前日の Homework for Life から
- 「転」が見つからないネタは捨てる

## 帰り（60分）
| 分 | やること |
|---|---|
| 0–15 | 会話の振り返り：うまく話せた場面・詰まった場面を1つずつ。詰まった場面は「どう言えばよかったか」を1文で書き直す |
| 15–20 | Homework for Life：今日いちばん話になりそうな出来事を1行 |
| 20–60 | インプットの続き、またはネタを推敲（2分＝400–500字） |

## 声に出す練習
- 毎日（車の中）：その日のネタを1分で話す
- 日曜：ネタを1本、2分で話して自撮り → 良かった点1つ・直す点1つを書く
- 良いネタは実際の会話で使い、相手の反応をメモする

## 記録
- ネタ帳・Homework for Life：スマホのメモアプリに1ファイル
- 週次レビュー：その週のベストネタと、日曜の動画で見つけた改善点
