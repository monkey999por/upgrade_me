## 導入
- [ ] **あすけん**：目標を「1,900kcal / P170」に設定 → [02](02_nutrition.md)の基準メニューを「マイメニュー」に登録
- [ ] スマートウォッチのアプリで、歩数・睡眠の記録がオンか確認
- [ ] 筋トレの記録先を決める（スマホのメモ or 記録アプリ）
- [ ] **Instagramの匿名アカウント**を作る（本名・勤務先・地域が分かるものは載せない。位置情報オフ）
- [ ] 写真の撮影場所・スマホの位置・照明を決めてメモ（毎週同じ条件で撮る）

## 予約
- [ ] 一般歯科：虫歯チェック・クリーニング（矯正の前に済ませる）
- [ ] 矯正歯科2–3院の初診相談（「相談と同じ日に精密検査まで受けられるか」も聞く）→ 候補は [05](05_teeth.md)
- [ ] 理容室か眉サロンで眉を整える（W2まで）→ [03](03_face-neck-posture.md)
- [ ] 美容院・理容室でカット（8週間の途中で一度）
- [ ] 決まった日時をClaudeに伝える → calendar.html に入れる
