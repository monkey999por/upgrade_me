# 07 ヒゲ脱毛（医療レーザー）

## 範囲（カウンセリングで伝えること）
| 部位 | どうするか |
|---|---|
| 鼻下 | 無くす |
| 頬（頬骨の上・目尻〜こめかみまで） | 無くす |
| あごの横 | 無くす |
| **顎髭（あご先）** | **残す**。形はまだ決めていない |
| あご下 | どちらでもいい（院の勧めを聞く） |
| もみあげ | まだ決めていない |

- ヒゲの濃さは普通。予算より結果を重視。麻酔はまず使わずに試す
- **もともと肌の色が黒め**
- 顎髭の境目は、**残す側を広めにとって**もらう。照射した毛はほぼ戻らないが、残した毛はあとから削れる
- 顎髭の形・もみあげは、2–3回照射して薄くなってから決めてもいい

## 進め方
1. 下の院から2院のカウンセリングを予約する（無料）
2. 契約は[05の契約ルール](05_teeth.md)どおり。**まず少ない回数で1–2回受けて**、痛み・効果・予約の取りやすさを見てから回数の多いコースを決める
3. 照射は1–2ヶ月おき。ヒゲは5–10回以上かかる（濃さで変わる）。ダーマペンをやるなら照射と2週間以上空けて交互に

## 院
3部位のプラン（鼻下・あご・あご下）は、残したいあごが入っていて頬が入らないので**合わない**。頬を含むプランで、あご先を照射しないように指定する。

| 院 | 場所 | 合いそうなプラン（税込） | 特徴 |
|---|---|---|---|
| ゴリラクリニック 大宮院 | 大宮駅 徒歩9分 | **5部位（鼻下・あご・あご下・ほほ・もみあげ）6回 58,320円**・12回 100,620円／1部位だけ 6回 34,920円。初回の麻酔は無料 | 男性専門の医療脱毛。部位の分け方がはっきりしている |
| メンズリゼ 大宮院 | 大宮駅東口 徒歩4分 | **全部位 5回 59,800円**・10回 99,800円／頬・もみあげなど1部位 5回 29,800円〜。麻酔クリーム 3,300円 | 男性専門の医療脱毛。打ち漏れの再照射・薬は無料 |
| 肌クリニック大宮 | 大宮駅西口（アクロスキューブ大宮5F） | 1回：頬＋口囲 16,000円／全体 19,800円（2ヶ月以内の次の回は5%引き）。麻酔込み、初診料1,500円 | 皮膚科。ダーマペンも同じ院でできる。回数が多いと割高 |

## カウンセリングで聞くこと
- **顎髭を残す形で照射できるか**（どこまで打たないかを照射のたびに守ってもらえるか、マーキングするか）。打たない部位の分は安くなるか
- 頬・こめかみ・目尻はどこまで打てるか（目に近いところは打てない院が多い）。こめかみ・頬骨の上は「ほほ」に入るか、別料金か
- あごの横は「あご」と「ほほ」のどちらに入るか
- **肌の色が黒めでも照射できる機種か**（ヤグレーザー（1064nm）か蓄熱式が安全とされる）。やけど・色素沈着が出たときの対応
- 自分のヒゲだと何回くらいか
- 追加でかかるお金：麻酔・剃り残しのシェービング・キャンセル料・肌トラブル時の診察や薬
- コースの有効期限、次の予約が何週間先まで埋まっているか
- レチノールはいつから止めればいいか、照射の後いつから使っていいか
- 照射の当日・翌日の運動・入浴・飲酒の制限

## 照射の前後に守ること
| 時期 | やること |
|---|---|
| ずっと | 日焼けしない（日焼けした肌には照射できないことがある）。自己処理は電気シェーバーだけ（**毛抜き・ワックスはしない**。毛根がないとレーザーが効かない） |
| 前日〜当日 | 院の指示どおりに剃っておく |
| 当日 | 汗をかく運動・サウナ・長風呂・お酒は控える。照射は**木曜（筋トレの休み）**か、筋トレのあとに入れる |
| 2–3日 | 赤み・ぽつぽつ（毛のう炎）が出ることがある。**金・土の照射は避ける**（日曜の写真に出る） |
