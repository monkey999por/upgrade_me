# 03 顔・首・姿勢（フェイスライン）

- 顔まわりは全身の減量で変わる。ここでやるのは姿勢・むくみ対策・表情の練習
- **やらない**：ミューイング（舌を上あごに押し付け続ける）、首を太くする筋トレ、ガムを長時間噛む・硬いものを噛むトレーニング

## 車の中のルーティン（毎日・15分＝前半：表情筋7分 → 後半：発声・滑舌8分）
運転中は前を見たまま、手はハンドルのまま、目を閉じない。首を大きく動かすものは信号待ち・駐車後だけ。

### 走行中（口・舌・声だけ）
| # | 内容 | 回数 |
|---|---|---|
| 1 | 「あ・い・う・え・お」を大きく口を動かして発声（1音2秒） | 10往復 |
| 2 | 「う」の口で唇を突き出し、右 → 左、上 → 下へゆっくり動かす | 左右・上下 各10往復 |
| 3 | 舌回し：口を閉じて、舌先で歯ぐきの外側を一周。ゆっくり → 速く | 右10・左10 × 2 |
| 4 | ぶくぶく：口の空気を左右の頬・上唇の上・下唇の下へ移動させる | 30秒 × 2 |
| 5 | 口角を上げて5秒キープ → 戻す（歯を見せる笑顔） | 10回 |
| → | 後半は [06](06_voice-articulation.md) の車メニュー（V1–V7） | 8分 |

### 信号待ち・駐車後だけ
| # | 内容 | 回数 |
|---|---|---|
| 6 | ヘッドレストあご引き：あごを軽く引いて後頭部をヘッドレストに5秒押し当てる | 5回 |
| 7 | 上を向いて下あごを突き出し3秒 → 戻す。慣れたら舌先を鼻に近づけて5秒（**駐車後のみ**） | 10回 |

- 7でめまい・首の痛み・手のしびれが出たら中止

### 車に乗るとき
- 後頭部がヘッドレストにつく位置に座席を合わせる
- ルームミラーは背筋を伸ばしたときに見える高さに

## 毎日の姿勢ケア（5分、在宅日のトレッドミルの前後や入浴後）
| 内容 | 回数 |
|---|---|
| あご引き（チンタック）：壁に背中と後頭部をつけ、あごを水平に引いて5秒 | 10回 × 2 |
| 胸を開くストレッチ：ドア枠に前腕をつけて胸を前に出す | 30秒 × 2 |
| 背中の上部を反らす：丸めたタオルを肩甲骨の下に置いて仰向け | 1分 |

## セルフマッサージ（夜の入浴後・3分）
その日のむくみを取るためのもの。
| # | 内容 | 回数 |
|---|---|---|
| 1 | 鎖骨の上のくぼみと下のラインを、内側から外側へ軽くさする | 左右 各10回 |
| 2 | 片手で鎖骨の下を押さえ、顔を斜め上に向けて首の前を伸ばす | 左右 各15秒 × 2 |
| 3 | 人差し指の第2関節を、あご下の骨のすぐ内側に当て、あごの先 → あごの角の手前まで軽く押す | 左右 各3往復 |

- **首の横の脈が触れるところ（あごの角の下）は押さない・揉まない**
- 痛いほど押さない。しこりや痛む場所があれば受診

## お店（小顔マッサージ）
この8週間は通わなくてよい。行くなら：
- ○ 「その日のむくみが取れる程度」と説明している店
- ✕ 「骨格が変わる」「エラの骨を押し込む」と宣伝している店、首をボキッと鳴らす施術、エステのHIFU

## 目元（目を大きく見せる）
| 原因 | 対策 |
|---|---|
| 朝のまぶたのむくみ | 塩分・夜遅くの食事・お酒を控える。写真は起床直後に撮らない |
| 顔全体の脂肪 | 全身の減量 |
| 眉がぼさぼさ | 眉を整える（下の「眉」） |
| 近視用メガネ | 写真・カメラありの会議はコンタクト |
| 目を細める癖 | 眼科で視力を測る |
| 無表情 | 目元の表情トレーニング |

### やってはいけないこと
- 目をこする、まぶたを強く引っ張る（コンタクトを外すときも）
- おでこ（眉）を持ち上げて目を開ける
- 目を指で押す

### メガネとコンタクト
| 場面 | どちら |
|---|---|
| 日曜の写真・自撮り動画 | コンタクト |
| カメラありの会議・プレゼン | コンタクト |
| テレワークでカメラなし | メガネでOK |

- コンタクトをつけたまま寝ない
- メガネを作り直すなら、度数−4.00以上は薄型（高屈折・非球面）レンズに

### 目元の表情トレーニング（家で1分。車ではやらない）
| # | 内容 | 回数 |
|---|---|---|
| E1 | 眉を指で押さえ、目をぎゅっと3秒閉じる → 眉を動かさずに目を開いて3秒 | 5回 |
| E2 | 下まぶただけを少し持ち上げて3秒 → 戻す | 5回 |
| E3 | 口を閉じたまま、目元だけで笑う（鏡で確認） | 5回 |
| E4 | 30cm先の指先と遠くを交互に5秒ずつ見る | 5往復 |

- E3は写真を撮る前に1回やる

### 眉
- 最初に一度、理容室・眉サロンで整えてもらい、その形を自分で維持する
- 眉と目の間の余分な毛を取る。細くしすぎない

## 横顔のチェック
### 横顔写真
- 同じ場所・照明・距離、スマホは三脚か棚に置いて目の高さ
- まっすぐ前を見た自然な姿勢で（上を向かない）
- 起床後1時間以上たってから撮る

### 仕事中のライブカメラ
- 仕事中はカメラを常にオンにして、見られている前提で過ごす
- 気づいたら：あごを軽く引く・背筋を伸ばす・口を閉じる

## 写真の保存
- 毎週日曜、正面・横・背面・横顔の4枚をスマホの専用アルバム（「upgrade_me」など）に入れる。SNS・共有アルバムには上げない
- Claudeには送らない。前の週・Day1と自分で見比べ、気づいたことだけ報告に書く
- 最終判定のBefore/Afterはこのアルバムの写真で作る
