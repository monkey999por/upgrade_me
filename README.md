## ゴール
- **脂肪を本気で減らす**（体重の数字は目標にしない）。1,900kcal＋ジムの有酸素＋1日1万歩で脂肪を落とし、筋トレ週5回で筋肉を戻す
- 毎日やることが決まっている（→ calendar.html）
- 目標から外れたときの対応が決まっている（→ [recovery-rules](plan/recovery-rules.md)）
- 自分の見た目を毎日・毎週直視する（鏡・週1回の写真と動画）
