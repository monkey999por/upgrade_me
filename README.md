## ゴール
- **太っている状態をなくす＝脂肪を本気で減らす**。体重の数字は目標にしない。1,900kcalの赤字＋ジムの有酸素（HIIT・傾斜ウォーク）＋1日1万歩で脂肪を落とし、ジム中心の筋トレ週5回で筋肉を戻す
- 毎日やることが具体的に決まっている（→ [calendar.html](plan/calendar.html)・[02 ルーティンのやり方](plan/02_daily-routine.md)）
- 数値で管理し、目標から外れたときの対応まで決まっている（→ [08 リカバリルール](plan/08_recovery-rules.md)）
- 自分の見た目を毎日・毎週直視して、変化を実感できる（鏡・週1回の写真と動画・Instagram匿名アカ）
