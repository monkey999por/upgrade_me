# 週次レビュー（毎週日曜）

日曜に下の「送るもの」をClaudeに貼る → 判定と記録はClaudeがやる。

## 日曜の流れ
1. 起床後すぐにウエストを測る（[測り方](../plan/goals-kpi.md#ウエストの測り方)）
2. 8:00以降に写真4枚（正面・横・背面・横顔、コンタクトで）→ スマホのアルバムに保存
3. Claudeに「送るもの」を貼る
4. 夜：1分原稿の録音（[06](../plan/06_voice-articulation.md)）→ 数字は翌週の報告に

## Claudeに送るもの（コピーして埋める）
```
W○ の報告
- 朝の体重（7日分）：日__ 月__ 火__ 水__ 木__ 金__ 土__（アプリのスクショでもOK）
- 体脂肪率（今朝）：__%
- ウエスト：__cm
- 平均睡眠：__h / 平均歩数：__歩（ウォッチのアプリの週平均）
- 食事：量を守れた日 __日/7日・外食や食べ過ぎ __回
- 運動：筋トレ__回（U/L/Push/Pull/Legs）/ ベンチ__kg×__回・ハックスクワット__kg×__回・チェストサポートロー__kg×__回・懸垂__回 / HIIT__回・傾斜ウォーク__回
- 毎日の習慣（ざっくり）：車のルーティン・日焼け止め・姿勢ケア → ほぼ毎日 / 半分 / ほぼなし
- 声：1分原稿__秒・噛んだ__回・語尾が消えた__か所
- 肌・歯：夜の洗顔 __日/7日・矯正の進み具合
- 一言：良かったこと・きつかったこと
- 写真：チャットに貼る or tracking/photos/ に置いた
```
- 写真はチャットに直接貼るか `tracking/photos/` に置く（例：`W1_front.jpg` `W1_side.jpg` `W1_back.jpg` `W1_profile.jpg`）

## 週ごとのメモ

### W1（9/27–10/3）
- ウエスト −4.5cm は1週間の脂肪の減り方としては大きすぎる。むくみ・測る位置のずれが大きいはず。W2で[測り方](../plan/goals-kpi.md#ウエストの測り方)どおり3回測って確認し、開始値を見直すか決める
- 体重は今朝の1回だけなので7日平均は出せない。W2から毎朝の値を7日分
- 筋トレ開始で筋肉痛が強かった（初週は普通。2週目から軽くなる）
- ご飯を食べ過ぎた感じあり → 来週はご飯を毎回量る。肉・油は今まで通り
- 未報告：体脂肪・睡眠・歩数・筋トレ回数と重量・写真
