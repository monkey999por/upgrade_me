# 週次レビュー（毎週日曜・Claudeと一緒に）

毎日の数値は各アプリに任せる（体重・体脂肪＝体組成計のアプリ、歩数・睡眠＝スマートウォッチ、食事＝あすけん）。手入力の日次記録はしない。
**日曜に下の「送るもの」をClaudeに渡す → Claudeが計算・判定して、このファイルに記録する。**

## 日曜の流れ
1. 起床後すぐにウエスト・首回りを測る（測り方は[05](../plan/05_face-neck-posture.md)）
2. 8:00以降（起床後1時間以上たってから）に写真4枚（正面・横・背面・横顔、コンタクトで）→ Instagramに投稿
3. Claudeに「送るもの」を渡す
4. Claudeの判定を受けて、来週の出社日を [calendar.html](../plan/calendar.html) で選び、筋トレの日を決める（[01](../plan/01_week-rules.md)）
5. 夜：1分原稿の録音＋2分トークの自撮り（[09](../plan/09_voice-articulation.md)）→ 数値は翌週の報告に入れる

## Claudeに送るもの（コピーして埋める）
```
W○ の報告
- 朝の体重（7日分）：日__ 月__ 火__ 水__ 木__ 金__ 土__（アプリのスクショでもOK）
- 体脂肪率（今朝）：__%
- ウエスト：__cm / 首回り：__cm
- 平均睡眠：__h / 平均歩数：__歩（ウォッチのアプリの週平均）
- 食事：だいたい守れた / 半分くらい / 崩れた（あすけんの週平均kcal・タンパク質がわかれば）
- 運動：筋トレ__回（U/L/Push/Pull/Legs）/ ベンチ__kg×__回・スクワット__kg×__回・ロー__kg×__回・懸垂__回 / HIIT__回・傾斜ウォーク__回
- 毎日の習慣（ざっくり）：車のルーティン・日焼け止め・姿勢ケア → ほぼ毎日 / 半分 / ほぼなし
- 人と関わる枠：__回 / 初対面__人 / 新しい挑戦：
- 声：1分原稿__秒・噛んだ__回 / 2分トークの「えー」__回 / ベストネタ：
- 肌・歯：ダーマペン・矯正の進み具合
- 一言：良かったこと・きつかったこと
- 写真：チャットに貼る or tracking/photos/ に置いた
```
- 写真は Instagram の URL ではなく、**チャットに直接貼るか `tracking/photos/` に置く**（InstagramのページはClaudeから読めないことが多い。`tracking/photos/` はgitに入らない）
- ファイル名の例：`W1_front.jpg` `W1_side.jpg` `W1_back.jpg` `W1_profile.jpg`（Day1は `W0_...`）

## Claudeがやること
- ウエスト（開始比）を [00の目標ライン](../plan/00_goals-kpi.md) と比べる。7日平均体重と「週の体重変化」、主要種目の重量の伸びも計算する（体重は減るペース（週0.4–0.8kg）を見るために使う）
- [08のルール](../plan/08_recovery-rules.md)を上から当てはめて、**来週変えることを1つだけ**決める（なければ「変更なし」）
- 写真を前の週・Day1と並べて変化をコメントする
- 下の表とメモに記録する
