# 週次レビュー（毎週日曜）

日曜に下の「送るもの」をClaudeに貼る → 判定と記録はClaudeがやる。

## 日曜の流れ
1. 起床後すぐにウエスト・首回りを測る（[05](../plan/05_face-neck-posture.md)）
2. 8:00以降に写真4枚（正面・横・背面・横顔、コンタクトで）→ Instagram
3. Claudeに「送るもの」を貼る
4. 来週の出社日を calendar.html で選ぶ
5. 夜：1分原稿の録音＋2分トークの自撮り（[09](../plan/09_voice-articulation.md)）→ 数字は翌週の報告に

## Claudeに送るもの（コピーして埋める）
```
W○ の報告
- 朝の体重（7日分）：日__ 月__ 火__ 水__ 木__ 金__ 土__（アプリのスクショでもOK）
- 体脂肪率（今朝）：__%
- ウエスト：__cm / 首回り：__cm
- 平均睡眠：__h / 平均歩数：__歩（ウォッチのアプリの週平均）
- 食事：だいたい守れた / 半分くらい / 崩れた（あすけんの週平均kcal・タンパク質がわかれば）
- 運動：筋トレ__回（U/L/Push/Pull/Legs）/ ベンチ__kg×__回・スクワット__kg×__回・ロー__kg×__回・懸垂__回 / HIIT__回・傾斜ウォーク__回
- 毎日の習慣（ざっくり）：車のルーティン・日焼け止め・姿勢ケア → ほぼ毎日 / 半分 / ほぼなし
- 人と関わる枠：__回 / 初対面__人 / 新しい挑戦：
- 声：1分原稿__秒・噛んだ__回 / 2分トークの「えー」__回 / ベストネタ：
- 肌・歯：ダーマペン・矯正の進み具合
- 一言：良かったこと・きつかったこと
- 写真：チャットに貼る or tracking/photos/ に置いた
```
- 写真はチャットに直接貼るか `tracking/photos/` に置く（例：`W1_front.jpg` `W1_side.jpg` `W1_back.jpg` `W1_profile.jpg`）
